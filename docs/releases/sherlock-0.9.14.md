# EWork Odyssey 0.9.14

日期：2026-09-17。平台：macOS Apple Silicon。

## 更新日志

- 增强协作画板交互组件的实时状态同步生成约束，统一通过共享状态通道处理多人操作和持续运行状态
- 新增生成结果校验与自动修复，减少组件只同步开始按钮、后续状态各自运行的问题
- 修复将“实时联机”“当前状态”等组件需求误判为外部最新数据检索的问题
- 已有未接入共享状态的组件需重新生成或更新需求后使用联机同步

## 发布范围

集成本地双客户端验收通过的组件共享状态生成校验与修复。沿用 0.9.13 已部署的协作服务，无服务端修改或数据库迁移。保留 Developer ID 与旧客户端兼容桥两条更新通道。按用户要求不做 Apple 公证，只执行聚焦检查、签名与包完整性检查、公开差分更新验证，不执行旧客户端全量安装重启测试。

## 使用边界

旧组件不会因升级自动改写；需要重新生成或更新需求以接入共享状态。第三方网页和任意旧脚本的本地变量不会自动同步。持续状态推进最小间隔 100ms，不定位为高帧率竞技游戏服务。
