# EWork Odyssey 0.9.13

日期：2026-09-17。平台：macOS Apple Silicon。

## 更新日志

- 新建看板根据首条任务自动命名，看板更多菜单新增删除入口
- 画布底栏改为统一图标工具栏，支持选择、框选创建组件、添加链接与语音创建
- 框选创建后自动返回选择工具并保留画布焦点，生成内容后保持用户指定的组件尺寸
- 统一组件选中描边与圆角，修复链接组件框选、层级和整理画布时的位置问题
- 增强网页组件兼容性，支持 Google、Bing 等网页在组件内显示，并优化缩放及选中切换时的显示稳定性
- 组件工具栏及右侧会话引用可读取网页正文，生成或发送前刷新页面内容
- 账户信息页新增退出登录入口，登录处理中提示改为正文颜色

## 发布范围

整合本地已验收的画布与账户功能。保留 Developer ID 与旧客户端兼容桥两条更新通道。按用户要求跳过 Apple 公证、stapling 及公证相关 Gatekeeper 验收；只执行聚焦检查和差分更新校验，不执行旧客户端全量安装重启测试。本次无服务端修改。
