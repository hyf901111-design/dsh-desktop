# Sherlock 0.8.9

日期：2026-09-07。平台：macOS Apple Silicon。

## 更新日志

- 修复研究容器因搜索权限判断不完整而反复返回空正文的问题。
- 生成完成后按实际内容自动扩展组件，长报告与 HTML 可完整展示。
- 整理画布按内容重新适配组件框尺寸，再排列位置，减少组件内滚动。
- 修复语音结束时空识别结果覆盖已有文字、导致生成失败的问题。
- 每个研究会话支持最多 10 个并发生成子任务，超出后有序排队。
- 精简组件生成范围，减少未要求的摘要、背景和 HTML 包装。

按用户要求跳过 Apple 公证与 stapling，保留双通道签名、包完整性与公开差分更新校验。
