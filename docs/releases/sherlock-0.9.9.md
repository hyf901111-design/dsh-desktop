# EWork Odyssey 0.9.9 发布记录

- 日期：2026-09-16
- 平台：macOS arm64；按用户要求跳过 Apple 公证，保留 Developer ID 与旧兼容桥签名。
- 用户授权合并当前本地代码、同步私有 GitHub hyf/main，并部署线上协作服务。

## 更新内容

- 协作看板由每位用户的主智能体执行对话和任务，支持创建子智能体并等待回传后继续
- 新增跨用户共享消息队列，显示发送者姓名，支持编辑、删除与插队，顺序执行避免上下文混乱
- 修复共享看板任务未绑定画板及子智能体未结束便交接的问题，服务版本不兼容时明确提示
- 个人看板支持右键刷新，完善组件操作与图片预览兼容
- 优化右侧PPT原地缩放与文件定位，正确定位子目录中的文件链接
- 修复任务结束后清单持续转圈，执行过程中及时核对任务进度
- 内置PPT制作技能升级至1.0.8，完善目录紧凑行距检查与交付校验
