# EWork Odyssey 0.9.12

日期：2026-09-17。平台：macOS Apple Silicon。

## 更新日志

- 修复协作对话中本人和其他成员的署名、气泡、复制按钮与时间对齐，明确显示智能助理归属
- 统一右侧对话操作图标尺寸，优化执行过程、正文和复制按钮间距，提高用户名与子智能体历史卡片的可读性
- 修复宽表横向滚动条缺失，增大表格辅助文字并优化历史卡片间距
- 修复五子棋等画布组件的点击坐标同步，支持跨成员落子、悔棋及重开后的状态恢复
- 协作成员菜单支持再次点击收起，管理与邀请弹窗支持点击蒙版关闭
- 文件目录和搜索结果支持手动刷新，以按钮旋转显示刷新过程，不再显示成功提示文字

## 发布范围

整合全部近期未合并且已验收的本地修改。保留 Developer ID 与旧客户端兼容桥两条更新通道。按用户要求跳过 Apple 公证、stapling 及公证相关 Gatekeeper 验收；仅执行聚焦检查和差分更新校验，不执行旧客户端全量安装重启测试。本次无服务端修改。
