# Sherlock 0.8.7

日期：2026-09-07。平台：macOS Apple Silicon。

## 更新日志

- 新增 Sherlock 账户体系，使用用户名、密码和邀请码注册，支持登录、退出及账户内修改密码。
- 基金研究等托管云端数据能力需要登录；用户自行配置的模型 API 不受影响。
- 设置改为全窗口左侧导航，登录与注册保留紧凑品牌浮窗；注册和修改密码增加二次密码确认。
- 优化账户图标、收起侧栏与更新入口布局，关于页面使用 Sherlock Logo。
- 更新下载同时显示百分比、已下载大小与文件总大小，保留下载后确认安装流程。

本次按用户要求跳过 Apple 公证，保留 Developer ID 与旧证书兼容通道签名。未执行 Apple 公证或 stapler，也未执行旧客户端全量下载、安装替换和重启升级测试。
