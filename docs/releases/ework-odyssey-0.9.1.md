# EWork Odyssey 0.9.1

日期：2026-09-08。平台：macOS Apple Silicon。

## 更新日志

- 产品统一更名为 EWork Odyssey，更新应用图标、深浅色标识与中英文标语。
- 组件生成增加格式验收、自动恢复和可读内容回退，减少生成失败后手动重试。
- 丰富监控面板、新闻、日历和报告等交互组件，并让内容更聚焦用户需求。
- 优化表格列宽和来源链接排版，精简组件顶部导航与重复信息。
- 修复点击组件内容无法选中整块组件的问题，保留内部链接和控件交互。
- 增强触控板缩放灵敏度，研究画布采用浅色纯白、深色深灰背景并保留点阵。
- 修复设置下拉菜单无响应，优化账户菜单图标、登录面板和随主题变化的用户名首字头像。

按用户要求跳过 Apple 公证与 stapling；保留双通道签名、安装包完整性、公开更新源及差分更新校验。通道目录名 notarized 不代表本次进行了公证。

已由用户验收的集成批次：20260908-02，验收提交 `c0fb315604727dc2556ee9849e939f143be7472d`。
