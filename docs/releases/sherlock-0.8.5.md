# Sherlock 0.8.5 发布记录

日期：2026-09-07。平台：macOS Apple Silicon。

用户授权发布 0.8.5 并明确跳过 Apple 公证。保留 Developer ID 签名、现有 Bundle ID 和双更新通道；不宣称通过 Apple 公证或 Gatekeeper。

## 更新内容

- 语音支持双按 Fn 开始、单按结束发送；长按 Fn 说话、松开发送。
- 修复语音创建组件后子代理未启动的问题，缩短前置检索等待，减少不必要的需求扩展。
- 丰富组件生成中的实时进度反馈，使用圆环加载状态并合并停止按钮，修正组件底部边角显示。
- 优化差分更新请求方式，减少因多段 Range 响应不兼容导致的全量下载回退；缓存或校验不可用时仍安全回退。
- 接入基金研究私有数据能力，并修复新增插件依赖缺失可能导致的客户端启动失败。

差分请求优化从安装本版本后生效，不能追溯修改旧客户端；0.8.4 升级到本版本仍可能全量下载。
