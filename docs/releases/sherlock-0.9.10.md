# EWork Odyssey 0.9.10

日期：2026-09-17。发布平台：macOS Apple Silicon。

## 更新日志

- 优化会话及画板切换性能，避免重复重建相同画板，首次离屏的 HTML 组件按需加载，平移后保留交互状态。
- 协作画板右侧复用普通对话的原生过程展示、工具详情和回复样式，实时呈现执行进展。
- 修复协作任务完成后回复未及时出现、需要切换会话才能显示的问题。
- 插队消息完成后，原任务自动恢复，原消息、执行过程和回复一起移至插队消息下方。
- 组件子智能体的独立任务采用区别于主对话的样式，便于识别组件进度与结果。
- 内置 PPT 制作技能升级至 1.0.9：封面副标题使用常规字重，去除目录首行上方横线，增加适合内容的左标题与正文、右图表版式。

## 发布范围

保留 Developer ID 与旧客户端兼容桥两条签名更新通道。按用户要求跳过 Apple 公证、stapling 与公证相关 Gatekeeper 验收。更新验证采用差分重建和 SHA-512 校验，不进行旧客户端全量安装升级测试。
