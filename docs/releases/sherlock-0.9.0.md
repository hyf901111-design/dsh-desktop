## 更新日志

- 新增构建模式，自动拆解研究工作台并并发生成独立组件；简单问答仍在对话中完成。
- 组件预设小、中、大三种规格，提前规划内容与尺寸，整理画布时统一同行大小并整齐排列。

- 优化连接中断、超时和限流提示，保留重试过程并减少不必要的生成内容。
