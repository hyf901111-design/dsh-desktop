# Sherlock 0.8.6 发布记录

日期：2026-09-07。平台：macOS Apple Silicon。

## 更新内容

- 基金研究默认使用 Sherlock 既有生产环境中的公共只读服务，用户无需配置基金 API Key。
- 支持单基金、对比、持仓风格和近期变化；保留证据日期、数据质量及缺失项说明。
- 服务端采用十分钟缓存、每 IP 每分钟 20 次限制、每日 1000 次研究尝试预算及最多 4 项并发。
- 客户端仅发送研究任务与基金代码，基金密钥仅保存于服务端 Secret。
