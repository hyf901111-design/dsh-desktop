# EWork Odyssey 1.4.0

日期：2026-10-27。平台：macOS Apple Silicon。

## 更新日志

- 对话首页新增快速开始运营区，提供研究看板、笔记随航、公司风格PPT和研究报告四类演示案例；案例会话和交付文件可保存并继续查看。
- 演示加入自然的虚拟指针、菜单选择、渐进输入、AI回复和等待过程；卡片以两行提示演示不消耗费用，显示完停留3秒后开始，发送后先显示用户消息再显示思考与回复，会话标题随实际进度更新。
- 行情看板演示逐步添加市场指数、五只自选股、个股行情、新闻、公告和日历，展示整理布局、拖动连线及智能容器补充组件；行情保留真实数据来源和刷新状态。
- 笔记演示增加右侧任务输入、选段改写、评论依据查看和券商预测口径核验；选区随指针拖动显示，完成后平滑回到文档顶部。
- PPT案例展示研报附件转20页公司规范汇报的完整流程；研报案例提供包含财务分析、专业图表、DCF情景估值、目录和来源说明的HTML与PDF成稿，交付后可直接在右侧预览。
- 四张创建卡片接通研究、笔记及内置PPT和研报技能；预置需求替换原有提示词并保留主题填写位置，技能封面仅在对话首页显示，可快速移除对应技能。
- 首页新增主题壁纸页签，沿用现有动态主题；优化页签滑动、壁纸悬停与浅色选中状态，以及运营卡片的通透材质、独立动态渐变、鼠标微透视和窄窗排版。
- PPT默认以预览模式打开，组件更多菜单、底栏和右侧文件工具栏支持切换编辑模式，并以短暂提示说明当前模式；统一底栏编辑按钮的文字与图标尺寸，减少不必要的编辑加载。
- 新增PPT点选和框选标注、编号图钉及备注气泡，可将多处标记与修改要求带入对话并交付独立修改版；支持重新定位、再次引用和删除标记，标签与备注自然同行排列。
- 更新内置PPT技能的封面、表格对齐、正文起排与图表规范，补充包结构和图表兼容检查，改善生成文件的打开与交付体验。
- 原生组件可在对话回复过程中自然呈现并保存状态、来源及数据；笔记内文件组件统一顶栏和底栏，支持在研究和笔记之间复用及引用。
- 交付文件以紧凑卡片显示真实文件类型，支持预览、下载、系统打开和在文件夹中显示；修正文件链接处理，移除成功打开及标注删除后的多余提示。
- 支持连续添加多个技能标签，统一输入区和已发送消息中标签的宽度、内边距、选中删除与自然换行；修复笔记技能选择、菜单闪动及命令选择后的光标位置，删除指令时不再自动补全。
- 新增当前工作区新笔记入口；收起侧栏时按项目、对话、研究、笔记组织创建操作，优化头像、通知与圆形悬停区域；左上角及项目目录的新建对话始终进入对话首页，修复笔记示例后的入口问题及导出弹窗关闭图标尺寸。
- 笔记检查更名为AI随航，系统评论者改为AI评论员，统一四芒星盾牌与运行呼吸动效；改写并复查通过的内容清除原问题高亮，保留未解决问题。
- 子代理列表和任务管理统一角色头像与运行提示；优化彭博模式图例、思维导图和图表对比度，以及任务规划栏展开收起箭头方向。
- 改进笔记组件的尺寸、对齐、配色、数据刷新、引用和导出衔接；增强研究来源、财报期间、完整表格字段和主题新闻筛选，并同步新增功能的英文界面。
