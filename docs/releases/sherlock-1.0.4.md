# EWork Odyssey 1.0.4

日期：2026-09-21。平台：macOS Apple Silicon。

## 更新日志

- 新增全局定时任务，可设置执行时间、重复频率与通知，并查看运行记录
- 画板组件支持独立定时更新，在组件更多菜单中设置任务，标题时钟标识显示任务状态
- 定时任务管理支持组件任务筛选与类型标签，统一运行、暂停、恢复和删除操作
- 优化定时任务页签切换、菜单层级、任务描述输入框与时间编辑器的关闭操作
- 从对话进入研究模式时，底部工具栏自然上滑淡入；切换画板时保持稳定

## 发布范围

- 发布用户已验收的全局及组件定时任务与界面优化。
