# EWork Odyssey 1.0.0

日期：2026-09-19。平台：macOS Apple Silicon。

## 更新日志

- 新增桌面操作能力：在授权后打开并操作 macOS 应用，支持观察窗口、点击、输入、拖拽和连续画笔；需使用支持图片输入的模型
- 优化桌面操作的截图、窗口定位和批量笔画执行，增加停止入口、超时与重复失败保护，减少长时间无效操作
- 对话模式支持在右侧浏览器打开网页、搜索及操作页面；改进已登录网页和懒加载正文读取，页面随侧栏宽度自适应
- 统一浏览器与画板中的智能助理光标和标签，任务结束后自动淡出，修复标签居中与窄栏裁切
- 内置 PPT 制作技能升级至 1.1.1：修复 PowerPoint 打开修复提示与封底乱码，封面副标题统一为 18pt，强化颜色、阴影、目录、间距、单字换行和留白检查
- 优化会话输入区及任务清单布局，移除多余遮挡；长消息自动换行并限制最大宽度，短消息靠右按内容收窄
- 修复侧栏标题遮挡、项目拖拽反馈延迟、左上角窗口拖动与 Logo 光标；补齐链接组件操作按钮并修复菜单展开时的选中描边
- 修复正文文件在 Finder 中定位错误，完善文件修改前补读与任务清单参数错误的恢复提示
