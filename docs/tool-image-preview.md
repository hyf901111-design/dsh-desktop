# 工具图片文件预览

工具返回的本地图片在对话执行过程下显示文件名，即使执行详情折叠也可点击。点击图片文件时，优先通过 `betterSidebar.openFile` 打开当前会话的侧栏文件预览；未启用侧栏服务时保留系统打开方式。没有本地文件路径的图片继续使用持久化附件图库，不伪造文件路径。

模型请求与用户预览分开处理：

- 保留原始会话和附件记录。
- LLM 最终适配器边界根据当前模型声明的输入能力，将纯文本模型请求中的工具图片递归转换为文件名、尺寸和“未读取像素”的文字说明。已有路径文本保留。
- 覆盖直接工具结果及 `tools-code-mode` 注入的图片上下文，包括已存在的历史记录和 prepared call。
- 支持视觉的模型仍接收图片；用户主动上传的图片继续走原有能力校验。
- `read_image` 允许为纯文本模型建立客户端预览，原有文件访问、类型及大小限制保留。

能力声明需准确；若配置将实际只接受文本的接口标为支持图片，此转换不会触发。此次没有改动用户的模型配置。
