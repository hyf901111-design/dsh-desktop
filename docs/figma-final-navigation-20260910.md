## 已实现

- 保留原常驻看板、折叠、搜索/Esc、分组、手动拖拽及最近更新时间业务。将节点尺寸接入真实行、标题、菜单和按钮；收起侧栏不渲染搜索入口。行悬停以更多图标替换时间，图标本身无背景框。
- 专用看板：重命名 / 共享协作 / 放回工作区。协作看板：重命名 / 管理协作；重命名绑定创建者权限。共享进行中同时在 UI 与调用入口禁止放回工作区，取消共享后恢复。
- 协作顶栏最多 3 个头像加 `+N`，完整人数来自成员名册，不把离线成员从名册删除。头像打开成员浮层，灰色圆形加号添加成员，“管理”直接打开画板设置。协作中不显示“创建协作”。
- 成员浮层支持搜索完整姓名、在线优先、真实 presence 更新、列表滚动、访问撤销后关闭、管理成员页入口。缺少活跃时间数据时显示“未在当前画板”，不伪造“几分钟前活跃”。
- 自己在顶栏/列表/管理处统一使用 Figma 原始橙黄粉背景 `/figma-self-avatar.png`；其他成员用 Figma 三组渐变色，按用户 ID 稳定映射。账户自身背景由主集成模块接入同一资源。
- 收藏按钮保留“设为常用”/“已设为常用”状态；星标、对勾、关闭、添加、多人图标使用 Figma 导出资源。
- 创建副本预览数量取实际 capture；邀请先核对 ID，发送到真实 `invitation.send`。加号邀请继续当前 boardId，不创建新的协作副本。管理成员、邀请、角色修改、撤销、另存副本、归档、结束/恢复共享及退出协作保留原服务调用。
- 管理中删除“侧栏显示”“自动刷新”。保留正确页签入口与权限。共享用户消息显式靠右随内容收缩、正文左对齐。
