# 看板组件内展示与交互修复（2026-09-14）

- 研究输入框只挂载至右侧对话栏；侧栏宿主不存在时移出 DOM，保留 React 草稿状态。
- 文件、网页与生成 HTML 保持原始阅读器，不以摘要替代；思维导图和正文在组件内部滚动。编辑正文左右 22px、上下 12px 留白。
- 选中组件后网页接收点击和滚轮。更多菜单保留修改名称、适用的编辑内容及移除操作，并加入刷新、浏览器打开。菜单退出期间保留角色和样式。
- 角标与卡片同时缩放，采用与卡片一致的 12px 圆弧，仅在角部悬停时显示。
- HTTPS 外部网页保留来源能力，加载原站脚本和嵌套图表。授权网页子树可在组件内导航；本地应用与离线生成页面的导航边界保持隔离。网页新窗口请求重定向至原组件；更多菜单的浏览器打开操作保持外跳。

## 聚焦验证

六个直接相关测试文件合计 176 项：组件阅读器、研究输入框、画布手势、链接授权、窗口导航和生成运行时。类型检查与本地开发构建通过；未执行全功能测试。

在隔离 Electron 客户端实测：
- 失败的 BTC 组件重新生成成功，交付 HTML 指标面板，带数据时点与来源；为检索快照，并非连续行情推送。
- shadcn Bar Charts 嵌套页面加载了 91 个柱形；Mobile 指标切换生效；window.open 跳转 Line Charts 留在当前组件。
- 真实滚轮将百度组件内部 scrollTop 从 0 改为 153。
- 更多菜单关闭前及关闭后 40ms 的背景、圆角和内边距一致。
- 不同缩放倍率下角标与卡片同比缩放；编辑框留白与导图滚动边界通过实际 DOM 几何检查。
