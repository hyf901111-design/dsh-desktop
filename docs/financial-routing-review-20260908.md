| 公开结果校验允许用能力目录冒充行情、接受缺少时间戳却标“实时”的记录 | 绑定查询意图、目录能力和状态，校验时间、证据唯一性、必需参数结构及状态与记录一致性 |

留存实现依据 Cloudflare 的 [Durable Object alarms](https://developers.cloudflare.com/durable-objects/api/alarms/) 和 [SQLite storage transactions](https://developers.cloudflare.com/durable-objects/api/sqlite-storage-api/)；alarm 异常由运行时重试，故障期间清理可能延迟。
