## 数据和运行时

主进程原子写入元数据，密钥由 Electron safeStorage 加密保存。渲染层仅接收脱敏结果。Harness 通过带随机令牌的本机桥调用，不从模型参数取得账号、工作区、父会话或定时任务身份。保存、撤权、切换账号、连接重启和迟到响应均再次校验版本与权限。

API 支持手工工具或 OpenAPI 3.0/3.1，MCP 支持锁定 SDK 的 STDIO 与 Streamable HTTP。工具只有明确授权后才暴露给模型；写入结果未知时保留结果未知状态，不自动重放。技能和声明式插件安全复制到托管目录，卸载不删除导入原文件或共享应用连接。

旧技能先只读扫描，再经用户确认复制；旧 MCP 和不受支持的包显示兼容提示，保留原配置。内置插件、应用和技能市场暂不提供尚未完成产品验收的条目，显示空状态；既有安装内容及用户添加的目录不受影响。工具目录保留连接配置模板，不生成账号、服务器或连接成功状态。周报整理与会议纪要两个示例技能已从内置市场目录撤下。

## 外部边界

- Google Calendar 已实现桌面 PKCE 授权，需用户的 Desktop OAuth Client ID 并在系统浏览器授权。当前没有产品正式 OAuth 注册或真实账号验收。
- Notion 内部集成令牌适配器保留，但已撤下默认添加入口和应用市场条目；公开 OAuth Broker、D1 迁移与目录 Worker 已实现并通过本地验证，尚未配置生产 Secret、注册应用或部署。
- 当前 MCP HTTP 支持无认证、Bearer 和自定义 Header。服务器驱动的动态 OAuth 发现/注册尚未交付，不能将其标为已支持。
- 本次仅做本地开发与聚焦验证，不递增版本、不公证、不上传、不推送、不修改公开更新源。

## 本轮前端修复

以 Figma 页面 `1254:71847` 为依据，读取列表、连接详情、市场、API/MCP 配置和技能导入节点。内容区边距 52px，列表行高 76px；详情按 630/314 双栏组织，窄工作区自动堆叠。API 支持基本配置、工具列表与结构化手动接口编辑，不把编辑工具等同于授予调用权限。

旧技能接入现在区分“已接入”“内置管理”“暂不能接入”，显示受阻资源、实际大小/数量及限制，提供 Finder 定位、重新选择完整包和重新检查。大模板、字体或已安装依赖仍保留原方式使用，不自动删减资源或修改原文件。

按用户后续可读性反馈，列表名称使用 16px，描述与正文以 14px 为主，状态、来源和辅助信息至少 13px，并提高次级文字对比度。保持 76px 行高与无装饰图标布局。工具权限编辑使用连接绑定的草稿；测试刷新不恢复用户取消的授权，新增或接口定义变化的工具不会继承旧草稿批准。

后续实机反馈：移除四类列表底部的常驻提示；技能页保留“接入旧技能”操作。插件与定时任务共用返回控件；右屏只使用原生面板自身的展开/收起按钮，不再维护插件专属的替代按钮或特殊位置。按钮、列表主区域、菜单、市场卡片操作、输入框补充中性悬停、按下和键盘焦点反馈，禁用态不会响应悬停。异步操作提供按钮等待状态和去重，并覆盖切页后状态查询失败的恢复，避免停留在永久禁用状态。
