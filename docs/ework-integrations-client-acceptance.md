## 数据和运行时

主进程原子写入元数据，密钥由 Electron safeStorage 加密保存。渲染层仅接收脱敏结果。Harness 通过带随机令牌的本机桥调用，不从模型参数取得账号、工作区、父会话或定时任务身份。保存、撤权、切换账号、连接重启和迟到响应均再次校验版本与权限。

API 支持手工工具或 OpenAPI 3.0/3.1，MCP 支持锁定 SDK 的 STDIO 与 Streamable HTTP。工具只有明确授权后才暴露给模型；写入结果未知时保留结果未知状态，不自动重放。技能和声明式插件安全复制到托管目录，卸载不删除导入原文件或共享应用连接。

旧技能先只读扫描，再经用户确认复制；旧 MCP 和不受支持的包显示兼容提示，保留原配置。内置目录含真实可安装包和可编辑的连接模板，不生成虚假账号、服务器或连接成功状态。

## 外部边界

- Google Calendar 已实现桌面 PKCE 授权，需用户的 Desktop OAuth Client ID 并在系统浏览器授权。当前没有产品正式 OAuth 注册或真实账号验收。
- Notion 内部集成令牌可在应用表单添加；公开 OAuth Broker、D1 迁移与目录 Worker 已实现并通过本地验证，尚未配置生产 Secret、注册应用或部署。
- 当前 MCP HTTP 支持无认证、Bearer 和自定义 Header。服务器驱动的动态 OAuth 发现/注册尚未交付，不能将其标为已支持。
- 本次仅做本地开发与聚焦验证，不递增版本、不公证、不上传、不推送、不修改公开更新源。
