# 内置免费数据源：实现与验证

新增 `ework-free-data-sources` v1.0.1：27项分类来源，15个免密钥适配器。来源目录和参数位于 `skills/ework-free-data-sources/references/sources.json`，每项保留官方文档、认证、缓存、许可条件和使用限制。适配器不接收任意URL或密钥，GET只读、不跟随重定向，按服务排队、缓存、限流退避，限制响应与记录数量，保留缺失值、单位、数据时间和获取时间。

`public_data_query` 纳入现有研究任务工具注册、作用域及进度反馈。父任务和允许联网的组件任务注入简短取数规则；默认免费源优先，用户指定源优先于默认。离线任务不获得此工具。默认免费取数不强制进入MCP刷新绑定协议；本工具交付快照，不能声称自动分钟刷新。原四个固定组件的数据与刷新实现保持原路径。

内置技能经过真实 FileSystemSkillProvider、IntegrationService 的目录、详情、运行时及不可删除/禁用验证；打包沿用 `skills → sherlock-skills`。组件生成技能更新至v1.34.0。

## 客户端生成及修复回归（2026-10-11）

在集成客户端使用现有 GLM-5.3-Flash Max 模型，通过真实“新建研究”流程生成三类工作台，共10个组件：宏观与行情4个、天气与地理风险3个、科研与软件生态3个。记录实际 public_data_query 调用，并逐一对比组件数据和接口返回；天气24个未来时点、GDP6条、ECB10条、Kraken30根、行情3条、地震20条、新闻10条、论文8条及两个软件计数均能对应真实数据。组件更新使用“编辑需求 → 更新组件”，更新期间保留已有内容；普通生成组件为快照，未自动建立刷新绑定。

客户端回归发现并修复：天气先筛除过去时点再取请求数量；父任务误写天气来源时以实际 MET Norway 返回信息纠正；原生表格原文链接写入 rows，DOI链接编码括号以防 Markdown 截断；不同请求数量不得共享同一归一化缓存；中国指数以点位而非证券币种标注。来源返回不足、缺失和限制均须如实保留。
