# 工作台生成失败、渐进展示与固定规格修复

2026-09-08；本地功能分支，未发布。

## 现场证据

真实客户端会话：创建加密货币研究工作台（session-62b718fc-a27c-4a58-8f09-db5e0ad618b5）。

链上数据与衍生品面板两次任务均失败（069352f4-2802-4a7e-b73d-21a494288b1c、c59da51f-00d4-4a38-ae9d-54dc1730de35）。最终子会话 584395c1-a33c-41d4-afe0-dbb167f2f607 和 0b2a7a4e-cd0b-438e-ba50-f92164a7e930 的请求没有任何工具；模型只返回 reasoning 块后以 completed 结束。没有把推理当作正文展示。

原因：`containerAllowsWebSearch` 把“链上与衍生品市场数据：BTC/ETH ...”中的“数据：”识别成用户已经给定数据，从而移除 web_search。现在只有明确离线、样例或实际提供数值的请求才走无搜索路径；“数据：字段名称”及“请提供数据”仍允许检索。

另一个主流币种行情面板已经进行 19 次搜索仍在运行。现在在同一子会话最多 8 次检索或 120 秒检索阶段之后收回该子会话的搜索权限，并发送一次构建提示；保留已有证据完成组件，缺失字段如实标注。已在途的请求正常结束，不重启整个检索过程。该限制不影响父会话和其他子任务。

## 交互与尺寸

- 工作台任务继续并发；只在 UI 中将新组件框按 500ms 间隔依次显示。时间戳持久化，刷新不会重新从头播放。
- 保留真实公开回报和检索主题，另增加当前组件的简短任务状态。识别 version 开头的 JSON，避免把构建内容误判为研究回报。
- 固定 small 720×360、medium 720×600、large 720×840；同排提升至共同规格。
- 模型收到实际外框与内容高度预算、正文与表格行列限制；组件完成后不任意伸高，HTML 测量也不覆盖固定规格。
- 整理画布将新旧生成组件统一到三档规格并按行对齐；其他文件和链接保留原布局逻辑。旧长内容保留，超过固定框时可滚动查看；新生成内容通过预算精简。
