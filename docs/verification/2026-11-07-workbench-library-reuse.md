# 看板工具复用组件库与节点联动（2026-11-07）

## 需求与实现

研究模式以客户端现有组件库作为基础能力。先判断原生组件能覆盖的需求，直接创建对应原生节点；其余内容按真实数据生成可视化，同一工作台可以混用。组件模板提供呈现与交互约束，不要求业务数据填满模板。

- 复用同一组件目录的自选、行情、指数、新闻、公告、个人日历；不是新增一套近似模板。个人日历不冒充经济事件数据源。
- 看板调用支持 `panel.library: {id, options}` 和根级 `links: [{sourcePanel, targetPanel}]`。使用实际节点 ID 建立自选到行情/新闻/公告、行情到新闻/公告的联动。
- 原生组件覆盖不了的来源、区间、财务字段或交互配置保留为数据生成任务，不替换证券、不伪造数字、不丢弃原需求。
- 使用真实页签与页签内成员关系组织页面，布局逐页签计算；面板上限扩为 30，支持三个实体各自的互补视图。
- 财务缺项仅在显式允许缺失时保留为空，不补零。多源绑定、刷新和证据使用同一 16 请求上限，原字节预算保持。
- 格式修复保留原子会话的真实响应与提交校验工具。修复期不重查数据，校验报错可继续修正提交；不靠一次性 JSON 输出赌模板正确。
