# 研究画板创作与剪贴板：开发验证记录

日期：2026-09-03。版本保持 0.7.9。本记录是隔离开发验证，不代表用户验收或正式发布。

## 已实现的用户路径

- 选择或框选组件后，使用「基于所选创建」输入需求，以所选资料生成独立的原生组件。读取已授权网页正文及文件正文，冻结证据和提示词供重试；不会修改原组件。
- 在画板粘贴文字、图片或文件；文字直接成为可编辑组件，不调用模型。支持的文件复用原有安全预览，不支持的文件显示文件卡片和「在文件夹中显示」。
- 复制一个或多个组件，在同一或另一研究画板粘贴。新组件使用独立身份及授权，保留相对位置；整组粘贴可以一次撤销、重做。
- 组件右键菜单提供复制，画板背景右键菜单提供粘贴，空剪贴板禁用粘贴。输入框、编辑器、网页和已有文本选区保留原生操作。
- 资料弹层去掉「发送时检查」一列，名称前显示对应类型图标；保持外部标签紧凑尺寸和弹层开关尺寸。

## 实现取舍及边界

1. 使用一次 Electron clipboard.write 同时写文本与含不透明快照引用的 HTML，避免 writeBuffer 覆盖其他格式。其他应用若去掉元数据，回退为普通文本粘贴，不执行任意 HTML。
2. 不支持的文件只定位到 Finder，不直接启动任意脚本或程序；用户需再显式打开文件。
3. 所选资料的首次成功读取结果，通过既有任务记录及父任务限定的检查接口冻结；不新增任意路径读取接口。代价是任务记录保存一份有上限的证据。
4. 复用现有多键存储，先写入再一次发布并记录历史；失败执行补偿并显示错误。整组撤销及普通写入失败已验证，但不承诺断电或持续磁盘故障期间的多文件崩溃原子性。

资源仓库有明确容量和文件大小上限；超限会报错，不静默截断原文字或假装导入成功。本次不引入可能误删历史副本的自动清理。
