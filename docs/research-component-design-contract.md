## 落地边界

- AI 输出继续使用原 version 1 schema；HTML 仅有 version/type/title/html 四个字段。没有新增必填字段，历史组件仍可恢复。
- 宿主提供主题、字体、控件基础、生成状态和工具栏。模型负责真实业务内容、图表数据、语义 HTML、内容布局和交互。
- 新生成的 HTML 经过设计校验，失败在原任务内自动修复一次。仍失败就显示可重试错误，不把静态说明冒充交互组件，也不覆盖原来有效的内容。
- CSS/HTML/脚本静态检查不是对任意动态脚本视觉结果的数学证明；宿主重要样式层和 Chromium/客户端验证共同约束结果。业务图形允许专用颜色，禁止把控件色和数据色混为一个 accent。
- 业务状态背景可包裹中性来源链接与按钮；背景不会因后代包含控件而被当成控件色。颜色 token 的嵌套 fallback 逐层校验，允许全为中性角色的 fallback，拒绝藏于 fallback 的业务色、自定义变量或字面色。

## 生成结果

- 壳圆角 8px、标题区 48px，业务标题 13/20。业务内容内边距 12px。
- HTML 不再重复外层业务题名。仅对文档首部明确页面标题做题名主体精确校验；单个尾括注视为说明，修复须原字保留该说明。不把同名分节标题或后置标题当成重复；修复保留来源、连接状态及共享回调，宿主不隐藏或删除业务 DOM。该类修复还与原输出做规范化 DOM 签名比对，除题名外的节点、属性、业务文本、CSS 和脚本均须保持，JSON title 不得改名规避；带 ID/事件的题名保留节点，只清重复文字。
- 原稿标题右侧的期间、单位或来源使用 `<meta name="sherlock-header-note" content="2026中报">`，由宿主标题栏显示；9px/20px，中文 Noto Sans SC Regular、数字 DIN Pro Medium。只读文本，不执行标记；按钮显现时留出操作区，长文保留完整提示。
- 默认 fund72 指标块高 64px、圆角 5px，指标数字 23/26；标签 9/14。不同业务原稿可以保留有来源的排版关系。
- 业务输入/select 高 28px、圆角 6px、边框 0.65px；按钮高 28px、圆角 7px。手动生成编辑器有独立规格，不套业务表格控件尺寸。
- 语义组件：`.research-primary` 或 `[data-sherlock-variant="primary"]`；`.research-secondary`；`.research-metric` / `.kpi-card`；`.research-metric-value` / `.research-metric-label`；`.research-numeric` / `[data-sherlock-numeric]`；`[data-sherlock-status="success|warning|danger|info"]`。
- 链接、分页、选项卡及普通选中使用中性色。宿主画布外的蓝色选择边界维持原稿。
- 图表不额外套装饰大卡，不把画布点阵复制到最终 HTML。表格数字对齐，保留实际行数、单位、来源和缺失说明。内容不能为了视觉一致被截断或整体缩小。
- Light/Dark 通过宿主 `sherlock-theme-change` 在同一 DOM 更新。输入值、筛选、共享状态和滚动位置不重建。Canvas 图表订阅事件重绘颜色。

## 生成状态与手动拉框

- 点阵使用 21Q 六个 Light/Dark × wide/tall/compact 的完整源点场，保留逐点路径、大小和透明度，不再重复单点叠统一遮罩。原始格距约9.921px，底色 Light `#FAFAFA` / Dark `#030303`，底部渐隐与亮度分布按源保留；任意手动尺寸沿原格距延展采样，不拉伸点形。
- 只对背景流动，前景图标、标题、阶段、详情、计时及工具保持稳定。7秒周期、沿网格向左上5列/1行是明确的实现参数；Figma静帧未提供动画时间线，不将这些参数标为原稿测量值。循环端点无跳变，停止在当前相位定格，重试恢复流动。
- running/retrying 流动；等待、停止、失败、暂停静态；减少动态效果偏好下静态。尚无实际暂停能力的入口不得呈现假“继续”。
- hover/focus 不使用背景模糊遮罩；右上角对应功能 icon，每个有可读名称和气泡提示。停止先进入 stopping，最终结果以任务真实终态为准。
- 手动框保留 x/y/width/height，输入、提交、生成、失败重试、完成均不得重置为自动 Bento 尺寸。620×300、240×620、360×200 仅为原稿例子，不是 min/max。
- 边界使用画布世界坐标：x/y 表示框中心，width/height 表示未缩放尺寸。屏幕拖框先减去画布偏移和平移量，再除以 viewport.scale；宽高同样除以该缩放比例。它们不是截图像素或 Figma 文档全局坐标，画布平移/缩放不能改写已存边界。
- 输入流程：框选→空输入（禁用生成）→输入（Enter 生成，Shift+Enter 换行）→原位置生成→原位置结果；失败/停止保留需求和可用旧结果。仅手动框编辑器采用此规则；实现另兼容 ⌘/Ctrl+Enter，并在输入法合成中忽略 Enter 提交。提交按钮沿用手动编辑器 92×32、r8。
