# 研究看板组件实现合同

来源：Figma `Jkyr5rMvgM8GNH6E68xnqd`，规范页 `1314:71941`（21M），21H 场景 `1217:209998`、21L 状态、21P/21Q 手动组件。源稿核对日期：2026-09-22；当前宿主模式规则更新：2026-10-28。用户最新“组件内控件浅深色均用黑白灰”优先于历史蓝色控件文字。

## 当前模式与宿主外观

本节是当前客户端对话、Research、笔记组件的宿主规则。Figma 实例中的48px标题栏、历史客户端64px标题区是对应来源或旧版本的记录，不能覆盖本节，也不能机械改写原稿尺寸。生成器只提交内容，外框、标题、图标、刷新/引用/更多/关闭和缩放由所在模式的宿主渲染器负责。

| 模式 | 完成态外框与标题栏 | 正文与控件 |
| --- | --- | --- |
| 对话 | 独立消息卡，1px边框、8px圆角；标题栏最小34px，内边距上下5px、左右10px，gap6px；标题600、12px/16px | 普通正文14px、1.65行高，内边距12px/14px；标题按钮24×24px。金融正文直接复用FinancialWidget；不显示画布连接点 |
| Research | 完成卡无默认边框、4px圆角；标题栏34px，左右10px、gap6px；普通标题600、12px/16px，金融标题700、12px/16px；标题操作20×24px | 类型专属renderer/profile决定内容字号和留白，不给所有模板强设同一种正文。金融正文12px/16px、控件高24px；HTML业务控件沿现有28px规则 |

权威实现为 `scripts/lib/conversation-components.mjs` / `.css`、`research-grid-ui.mjs` / `research-grid-workbench.css`、`financial-widget-client.mjs` / `.css` 以及 `src/preload/notes/native-component-block.tsx` / `style.css`。HTML内容的字体、角色色和语义控件仍由 `html-artifact.js` 与 `workbench-style.js` 提供。标题、body和footer各自在实际容器内排版，长列表滚动，表格横向溢出；不能裁掉数据、缩小整卡字体或让正文压住状态条。quote搜索与标题复用宿主限宽规则，窄列隐藏重复标签，保留可操作搜索入口。

- **内容结构**：标准类型只交完整结构化数据，不另画同类图表或CSS外壳。模板不足时才交HTML，不能重复JSON title的页面题名、外框或宿主动作。正文分节标题、筛选行、图例、单位、业务详情及明确用户定制的内容布局照常保留，不把“去重复标题”扩大成删除全部标题。
- **主题与交互**：复用宿主token、字体、图标和语义控件；控件用中性色，业务图表/行情/状态保留其含义。默认不随机指定外框、装饰、控件或主题；用户明确的内容布局与业务配色仍优先。切换主题不重建DOM、清输入、丢筛选或改写数据，保留已存主题与尺寸。宿主操作不能由HTML伪造；没有真实能力的按钮不显示成可用操作。
- **生成与加载**：沿用所在模式已有生成/processing样式，状态来自真实请求与公开进展，不由模型编计时、进度或完成。Notes行内AI由宿主显示正在工作/停止；停止与失败保留需求和已有有效内容。对话依据真实保存回执挂载完成组件，不用占位符或隐藏画布冒充交付。
- **空态与错误**：未配置提供真实搜索/配置入口；来源确认无记录显示明确空态，取数失败或未取得行情显示缺失与重试。失败保留旧有效数据及其原时点，不能把空数组当获取成功。没有证券的同名“行情面板”创建quote和空symbols，保留证券搜索、周期、指标及未选标的提示，不猜证券或换成空indices。
- **来源与时间**：来源名称、原数据时点/报告期、实际获取时间、保存时间分开显示；未提供就说明缺失。创建成功不表示行情获取成功，组件创建时间不能代替获取时间；快照不声称自动刷新，只有真实绑定或原生数据服务能显示对应刷新状态。

运行时由 `design-policy.js` 的 `COMPONENT_SURFACE_STYLE_RULES` 提供共同指令；`component-skill.js` 在full/panel/selection每个profile的强制头注入；对话父智能体的 `CONVERSATION_COMPONENT_GUIDANCE` 使用同一导出。Notes组件子任务使用同一loader。内置skill是这些规则的可读入口，不能只更新文档而遗漏实际prompt。

## 落地边界

- AI 输出继续使用原 version 1 schema；HTML 仅有 version/type/title/html 四个字段。没有新增必填字段，历史组件仍可恢复。
- 宿主提供主题、字体、控件基础、生成状态和工具栏。模型负责真实业务内容、图表数据、语义 HTML、内容布局和交互。
- 新生成的 HTML 经过设计校验，失败在原任务内自动修复一次。仍失败就显示可重试错误，不把静态说明冒充交互组件，也不覆盖原来有效的内容。
- CSS/HTML/脚本静态检查不是对任意动态脚本视觉结果的数学证明；宿主重要样式层和 Chromium/客户端验证共同约束结果。业务图形允许专用颜色，禁止把控件色和数据色混为一个 accent。
- 业务状态背景可包裹中性来源链接与按钮；背景不会因后代包含控件而被当成控件色。颜色 token 的嵌套 fallback 逐层校验，允许全为中性角色的 fallback，拒绝藏于 fallback 的业务色、自定义变量或字面色。

## 生成结果

- 宿主外壳采用上方当前模式规则。下文有来源的HTML内容profile保留业务标题13/20与12px内容内边距，不把源实例的48px标题区重复画进正文。
- HTML 不再重复外层业务题名。仅对文档首部明确页面标题做题名主体精确校验；单个尾括注视为说明，修复须原字保留该说明。不把同名分节标题或后置标题当成重复；修复保留来源、连接状态及共享回调，宿主不隐藏或删除业务 DOM。该类修复还与原输出做规范化 DOM 签名比对，除题名外的节点、属性、业务文本、CSS 和脚本均须保持，JSON title 不得改名规避；带 ID/事件的题名保留节点，只清重复文字。
- 原稿标题右侧的期间、单位或来源使用 `<meta name="sherlock-header-note" content="2026中报">`，由宿主标题栏显示；9px/20px，中文 Noto Sans SC Regular、数字 DIN Pro Medium。只读文本，不执行标记；右上角两个功能按钮绝对定位浮于上层，hover 与键盘聚焦时均不占位、不改变标题或右侧文本的坐标、宽度及省略状态；移出后自然露出原文。长文保留完整提示，按钮保留功能名气泡。
- 默认 fund72 指标块高 64px、圆角 5px，指标数字 23/26；标签 9/14。不同业务原稿可以保留有来源的排版关系。
- 业务输入/select 高 28px、圆角 6px、边框 0.65px；按钮高 28px、圆角 7px。手动生成编辑器有独立规格，不套业务表格控件尺寸。
- 语义组件：`.research-primary` 或 `[data-sherlock-variant="primary"]`；`.research-secondary`；`.research-metric` / `.kpi-card`；`.research-metric-value` / `.research-metric-label`；`.research-numeric` / `[data-sherlock-numeric]`；`[data-sherlock-status="success|warning|danger|info"]`。
- 链接、分页、选项卡及普通选中使用中性色。宿主画布外的蓝色选择边界维持原稿。
- 图表不额外套装饰大卡，不把画布点阵复制到最终 HTML。表格数字对齐，保留实际行数、单位、来源和缺失说明。内容不能为了视觉一致被截断或整体缩小。
- Light/Dark 通过宿主 `sherlock-theme-change` 在同一 DOM 更新。输入值、筛选、共享状态和滚动位置不重建。Canvas 图表订阅事件重绘颜色。

### 有来源的场景模板

基金72的持仓表、四指标、行业条形图分别使用 `main[data-sherlock-profile="fund72-holdings|fund72-kpi|fund72-industry"]`。宿主提供排版与颜色，模型只填真实数据和必要的筛选行为；不手写 body padding 或覆盖模板字号、间距、奇偶行颜色。不同场景不互套模板，Lumos 不套基金持仓行高。

显式声明 profile 后，生成验收检查名称与必需语义结构：指标容器/项/标签/值，行业行/标签/轨道/条形/值，或持仓表格的 thead/tbody；有筛选或搜索时使用对应 class。宿主管理的排版节点不得以内联 `!important` 改写字体、留白或颜色。失败只补声明和语义 class 或移除冲突优先级，保留原数据、来源、控件、脚本及共享回调；不得删除 profile 绕过校验。业务条数不锁死，空数据、真实条形宽度和筛选显隐仍允许。

- 持仓：原稿 `1217:247167` / Dark `1217:255020`，556×400；表头25px、与首行间隔4px、行34px。五列均按原稿左对齐；中文与代码中的S采用 Noto Sans SC Bold，数字片段 DIN Pro Medium。正变化专用 Light `#B84343` / Dark `#FF9D9D`，负变化保持正文色，不套收益红绿。原稿搜索图标由宿主提供（外径8px、描边1.2px、柄4px）；选择器沿用原生语义与键盘行为，箭头源路径8×4、描边1.2px、距右12px，绘制视窗须留出描边而不裁边。数字使用DIN，斜线、分隔点、正负号按原稿使用Noto Regular；宿主限定字形映射直接覆盖已有产物，不修改文本和事件。
- 四指标：原稿 `1217:247146`，896×132；4列、间隔10px、块高64px、圆角5px；标签9/14、值23/26、说明8/11，中文单位保持原稿 Regular。
- 行业：原稿 `1217:247228` / Dark `1217:255081`，328×400；条形高7px、圆角2px、每行27px；标签9/18、数值10/18。业务条形图 Light `#005096 / #1EB9E1`、Dark `#0078B4 / #1EB9E1`，筛选控件使用黑白灰。比例按实际数值和明确量程计算，不为凑齐长度改变数据。

同数据验收须保留实际模型产物及来源节点，按原稿尺寸通过生产 renderer 渲染并测量，再核对真实客户端。人工 fixture 仅能证明样式层规则，不能冒充外部模型生成结果；不以隐藏内容、缩小字号或修改数据消除差异。

## 生成状态与手动拉框

- 点阵使用 21Q 六个 Light/Dark × wide/tall/compact 的完整源点场，保留逐点路径、大小和透明度，不再重复单点叠统一遮罩。原始格距约9.921px，底色 Light `#FAFAFA` / Dark `#030303`，底部渐隐与亮度分布按源保留；任意手动尺寸沿原格距延展采样，不拉伸点形。
- 只对背景流动，前景图标、标题、阶段、计时及工具位置保持稳定；详情区按下述规则滚动真实进展。7秒周期、沿网格向左上5列/1行是明确的实现参数；Figma静帧未提供动画时间线，不将这些参数标为原稿测量值。循环端点无跳变，停止在当前相位定格，重试恢复流动。
- running/retrying 流动；等待、停止、失败、暂停静态；减少动态效果偏好下静态。尚无实际暂停能力的入口不得呈现假“继续”。
- hover/focus 不使用背景模糊遮罩；右上角对应功能 icon，每个有可读名称和气泡提示。停止先进入 stopping，最终结果以任务真实终态为准。
- 手动框保留 x/y/width/height，输入、提交、生成、失败重试、完成均不得重置为自动 Bento 尺寸。620×300、240×620、360×200 仅为原稿例子，不是 min/max。
- 边界使用画布世界坐标：x/y 表示框中心，width/height 表示未缩放尺寸。屏幕拖框先减去画布偏移和平移量，再除以 viewport.scale；宽高同样除以该缩放比例。它们不是截图像素或 Figma 文档全局坐标，画布平移/缩放不能改写已存边界。
- 输入流程：框选→空输入（禁用生成）→输入（Enter 生成，Shift+Enter 换行）→原位置生成→原位置结果；失败/停止保留需求和可用旧结果。仅手动框编辑器采用此规则；实现另兼容 ⌘/Ctrl+Enter，并在输入法合成中忽略 Enter 提交。提交按钮沿用手动编辑器 92×32、r8。

## 自动工作台与过程入口（2026-09-22 修订）

- 自动规划的待生成卡统一为 280×200 世界坐标单位，九卡三列，横向间隔20、纵向间隔24，对照原稿895:28934。完成后才按内容尺寸布局。整理面板不能把自动卡误标为manual；已有用户手动框不能强制改写。
- “查看过程”打开当前组件 generationChildSessionId 对应的右侧子Agent页签；重试后使用新子任务ID，核对parent关系，禁止就近选择其它任务。没有已启动子任务时说明原因。卡片不展开过程列表，不增加高度。
- 公开工具调用、结果返回和已收到内容结构组成真实进展队列，生成中每900ms滚动一条；新事件到达优先显示最新条目。它是已有进展的轮播，不伪造新任务；禁止显示私有推理、凭据或内部地址。减少动态效果时只显示最新进展。900ms是本次实现参数，不声称是Figma原稿测量值。
- 搜索预算到期只标记待收紧；当前模型步骤结束后再撤销工具权限，避免已发出的合法工具调用变成unknown tool。仍保留任务总时限、取消与一次基于已取得证据的修复；空结果不能冒充完成。

## 行情场景 42

来源1217:212753，结构与文字采样见design/research-market42-source-audit.json。六个独立面板分别为六指标、K线+成交量、自选行情、行业热力、逐笔成交及市场广度。指标块76px、数字21px；表格正文11px。这些是行情场景规则，不套基金72的23px指标字体。

完成态尺寸分别为896×144、562×264、322×264、434×258、450×258、896×110，间距12；按内容顺序组合，不被通用S/M/L重新拉伸。超过原稿8行的表格按19.5px行高增高至600px上限后滚动；广度附加指标增加所需行高。六项原生KPI与行情模板同组时也采用单行896px横条。以上仅适用于自动完成态，生成中仍为280×200，手动框保留用户边界。

AI可输出version1/type=market的数据对象（metrics/table/candlestick/heatmap/breadth），由宿主转成现有HTML schema，负责主题、表格排序和完整数据查询。OHLC及成交量必须真实且满足高低价边界；热力面积必须有真实权重；来源和缺失说明保留。不把截图上无法读取的整段OHLC与未标示权重编造为同源数据。六指标、表格和市场广度可以按可读源值逐项对照，K线轨迹全量同数据比较仍需要原始序列。

## 页签图标

顶部页签、已打开页签菜单、新建页签入口共用16×16、1px描边、圆角端点/连接、currentColor的中性线性图标。对话、文件夹、任务/子Agent、定时任务、终端、浏览器、图片、差异、文档与未知扩展均有可识别图标；未知扩展使用通用面板图标，不留空。定时任务独立插入的页签沿用同一时钟路径。选中只改变中性前景/底色，不切实心或彩色风格。

## 回归入口

仅运行本次直接关联的测试：HTML 主题与沙盒、生成合同/修复、状态动作、手动 geometry、客户端补丁幂等性。Chromium 脚本 `scripts/verify-research-component-design.mjs` 使用真实 HTML 预览构建器检查两主题控件几何、作者 CSS 覆盖、图表/状态保留、输入和计数器连续性。

实际客户端须按本地测试手册从集成分支构建，保留原用户资料，检查完整主界面、拉框生成、hover、停止/重试及最终内容。自动验收与用户验收分别记录；不把自动通过写成用户已经接受。
