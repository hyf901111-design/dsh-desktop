# 30 类模板与数据刷新验收记录

- 30 个唯一模板：21 个金融变体，KPI、折线、柱状、表格、概览、资讯、研报、日历、甘特。
- Chrome：每类 320px、模板默认宽度、960px，深浅主题，共 180 个渲染场景；未观察到脚本错误、普通控件越界、无数据却仍可见的禁用时间选项。宽表使用内部横向滚动。
- 复验基金三类模板的最终字号覆盖：3 个尺寸共 9 个深色场景，正文/控件均不小于 11px；图形内文字仍以图表缩放后的实际尺寸为准。
- 52 个受影响模板/交互测试通过；7 个数据引擎聚焦测试和 4 个上下文授权测试通过；TypeScript 检查通过。
- 模板脚本：`scripts/component-template-gallery.mjs` 生成本地验收页；`scripts/component-template-audit.mjs` 在 Playwright page 中执行尺寸与主题检查。

## 本次变更

- 已有真实结构化数据可直接填入固定模板，不再要求为每张卡片启动一个生成任务。
- 取数提示词优先发现用户已启用的插件，按任务选择来源；不固定只用同花顺。动态 MCP 参数字典显式保留自由键值。
- 标准字体提升到可阅读大小；长时间轴按实际宽度减少可见刻度，完整数据仍可查看。
- 周期接口取数有独立持久化数据绑定、合并请求、暂停、失败退避、陈旧结果防护和同数据跳过重绘。
- 更新保留模板 ID、标题、位置、手动尺寸，以及原生图表图例和选点；HTML 组件按模板版本保留交互记录。

## 边界

- 新的数据绑定执行器目前支持个人工作台；共享工作台的旧刷新路径未纳入本次验收，不能声称已支持。
- 应用关闭时不执行刷新；恢复后处理到期任务。
- 真实源数据的可用性、历史深度、权限、限额取决于接口；失败保留上次数据，不能保证所有外部接口永不报错。
- 上述渲染检查不等同于实际 MCP 业务调用、完整工作台创建或整窗闪动验证。后续在真实安装包中记录证据。
