# OpenTerminal 组件样式试用

当前看板底部的“看板样式”第三项为 **彭博模式 / Bloomberg mode**，使用配套的实色终端图标，位于深色模式右侧、易方达模式左侧。其布局来源仍为 OpenTerminal，内部标识保留 `openterminal`，兼容已保存的数据。它是本地、可关闭的全看板试用覆盖，开启后所有已有和新打开的看板均使用此模板，不覆盖各看板已保存的原有样式。默认不启用；原来的浅色、深色和易方达模式保持可选。点击任意原模式可退出全看板试用，其余看板恢复各自原来外观；切换不会改写组件数据、生成需求或布局。

这套模板由宿主应用于当前组件和后续生成的组件，无需模型重写 HTML。原生金融组件、结构化表格与图表、自定义 HTML 共用黑色表面、橙色强调、细分隔线和等宽数字字体。HTML 仍使用原有受限展示桥与沙盒，不添加联网依赖或扩大权限。

组件顶栏仍由 `WorkbenchChrome` 提供，保留标题、刷新状态、提问、放大、菜单及关闭等原有元素。底栏的数据来源、刷新频率、状态与数据源设置入口沿用现有实现。仅修改外框与展示样式，保留 34px 顶栏及原有底栏布局。

试用模式使用直角细边框，标题区域拖动组件，右下角手柄同时缩放宽高。继续使用 EWork 的网格、碰撞避让、最小尺寸、布局保存及 Escape 取消；右下角缩放作用于当前卡片。切回原模式后恢复原有选中状态下的宽度 / 高度手柄。

视觉来源：[ErTasselli/OpenTerminal](https://github.com/ErTasselli/OpenTerminal)，参考提交 `aed097c680cd8ec1c391ae06966babe7d6d91fc6`。适配其终端配色、面板边框与右下角缩放手柄；未导入其应用、数据服务、视频频道或 React 网格依赖。MIT 许可见 `build/openterminal/LICENSE`。

验收范围：按看板切换与恢复、重新打开后的偏好、原生与 HTML 组件展示、实际生成后的样式、标题拖动、右下角缩放与取消、原有顶底栏操作，以及一键整理后的阅读布局。本地试用不代表正式发布或用户已接受此样式。
