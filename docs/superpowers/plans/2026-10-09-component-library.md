# 固定金融组件库实现计划

> 按已确认 Figma 24C/24E 直接实施，采用 executing-plans 内联执行。

**Goal:** 底栏四项组件库直接放置自选股、个股行情、市场指数、新闻列表；全部操作在组件中完成。
**Architecture:** 既有 React 原生看板宿主、共享严格金融组件契约、可信主进程公开行情/资讯适配器、看板现有持久化/历史/只读边界。动态行情来自实际数据服务，设计示例不作为运行时数据。
**Tech Stack:** Electron/TypeScript，序列化 React 客户端补丁，SVG 数据图表，Vitest。

**Review Focus:** 只读/会话切换/账户切换，旧请求覆盖新选股，重复添加、市场同代码、拖拽排序丢行、长列表与页脚；补丁重入升级和恢复；接口元数据/日期/单位不能猜测；图表无数据与零值；画布已有组件及离屏整理。

### 2026-10-10 可用数据路径

默认内置 MCP 的接口发现正常，实际行情、指数和新闻业务请求返回 HTTP 402。用户授权更换实现方式，以组件添加后能显示数据为验收目标。

- 固定组件直接读取腾讯财经公开报价、K线、分时和证券联想；新闻读取新浪财经滚动资讯，关键词检索读取东方财富。用户 MCP 配置与其他工具路由不变。
- 主进程只允许固定 HTTPS 来源，复用 DNS 检查和连接固定，超时/有界响应，不执行 JSONP 脚本。登录及账户变化检查、缓存与请求合并、手动刷新绕过缓存继续生效。
- 公共报价使用上游交易日期、价格和原始百分比，保留缺失状态。成交量单位按来源为 A 股手、港美股股，不把周末读取时间标成行情日期。
- 美国证券联想的交易所后缀转换为报价接口代码，历史请求使用报价确认的完整交易代码；所选复权口径未提供时明确显示不支持，不静默换成另一口径。
- 分时绘制实际分钟价格折线及分钟增量成交量，标题/横轴显示时间，不伪造开高低收。美股公开分时暂不支持。
- 指数同时取得实际报价及最近 60 个交易日收盘走势；新闻保留真实标题、时间、媒体和原文链接。接口失效沿用组件重试与上次有效数据保留机制。

### 2026-10-10 分钟刷新与来源时刻

- 保留现有每 60 秒刷新；腾讯沪深报价失败、缺失或无有效价格时，只对缺失标的使用新浪公开报价，不覆盖主源有效数据。备用请求同样受固定 HTTPS 来源、账户隔离、超时与响应大小限制，不执行返回脚本。
- 原始交易日期 `asOf` 保持兼容，新增完整上游 `quotedAt`。沪深港使用当地 UTC+8，美股使用纽约时区并正确处理夏令时；最近获取时间独立呈现。
- 页脚按市场时区显示休市、盘前、午间休市；常规交易时段仅在上游时刻足够新时显示“更新中”，否则显示“时效待确认”。不凭周内时钟猜测节假日、停牌或实时授权。跨市场列表提示各市场时刻，悬停展开逐项来源、精确时刻和时区。
- 窄组件保留状态，来源和时间超长省略；完整信息与最近获取时刻仍可通过悬停查看。所有状态沿用三种主题和原有页脚高度。
- 新浪备用仅覆盖沪深报价；K线、分时与指数历史趋势继续使用腾讯接口，行情图表来源在提示中明确，美股免费实时 IEX 需另行账户配置，不混入本轮。
