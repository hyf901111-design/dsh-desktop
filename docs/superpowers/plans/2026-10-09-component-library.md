# 固定金融组件库实现计划

> 按已确认 Figma 24C/24E 直接实施，采用 executing-plans 内联执行。

**Goal:** 底栏四项组件库直接放置自选股、个股行情、市场指数、新闻列表；全部操作在组件中完成。
**Architecture:** 既有 React 原生看板宿主、共享严格金融组件契约、可信主进程 DataYes 适配器、看板现有持久化/历史/只读边界。动态行情来自数据服务，设计示例不作为运行时数据。
**Tech Stack:** Electron/TypeScript，序列化 React 客户端补丁，SVG 数据图表，Vitest。
**Spec:** Figma Jkyr5rMvgM8GNH6E68xnqd / 2190:373519、2190:373649、2190:374263、2190:374347、2191:373519、2259:384239。组件库264×216，工具栏375×46，自选股320×514、个股716×600、指数980×200、新闻620×340。现有34px共享组件标题。深浅主题。自选股名字粗体主级、代码弱化；涨跌色块、删除右键、行拖拽；加号内联联想。个股标题内选股、周期/复权/MA/VOL/MACD，密集图表。未知数据不填0、不补示例；来源时点、未登录、接口不支持和失败都明确显示。

**Global Constraints:** 排除三块已暂存实验；不替换共享客户端、不发布、不涨版本、不推送；不跑全功能测试；本地中文提交。固定配置无独立面板。远程请求由主进程固定路由，客户端不得提交任意接口URL/密钥。
**Review Focus:** 只读/会话切换/账户切换，旧请求覆盖新选股，重复添加、市场同代码、拖拽排序丢行、长列表与页脚；补丁重入升级和恢复；接口元数据/日期/单位不能猜测；图表无数据与零值；画布已有组件及离屏整理。
