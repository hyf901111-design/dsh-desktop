# 会话调用客户端能力实施计划

## Spec

用户要求从客户端会话输入自定义、组合触发现有功能。具体反例是笔记中的“导出这篇文档成 PDF，组件用易方达配色主题，并且不要显示组件的顶栏”，模型却错误声称没有权限。必须接通真实能力、执行并按结果回复，不能只识别导出关键词。现有笔记挑战回归并行继续，保护用户当前正文和历史。

## Global Constraints

- 工作目录为 notes-challenge-v16-20261021 功能 worktree；不构建或替换共享客户端，不推送或发布。
- 通用、类型化的语义能力目录；参数、当前上下文、可用性、执行结果、取消和请求身份均有明确边界。不暴露任意 IPC/JS 执行，不根据导出关键词分流。
- 会话和按钮复用已有底层处理器。现有真实账户/只读约束继续执行，不编造权限限制，不凭模型文字宣告成功。
- 保留笔记生成/预览/进度/图片/历史、用户富文本/组件/草稿。功能完成只运行相关聚焦测试，禁止全功能测试。
- 控制器专有文件：notes/challenge-controller.ts、challenge-ui.tsx、replacement-review.tsx、所有 notes-challenge-* 与 notes-replacement-review 测试及 packages 下 notes-challenge-*。Task 1 不修改这些文件。
- 每项通过验证的修改创建中文本地 Git 提交，只 stage 自己拥有的文件；其他并发脏文件不得包含。读 AGENTS.md 和相关 runbook。

## Task 1: 接通通用客户端能力目录与会话执行

在 src/main、src/preload/notes、packages/dsh-research-task-runtime 的现有 Notes generate 路径中实现完整纵向通道。先阅读 /tmp/notes-general-client-capabilities-inventory-20261022.md 及现有导出/组件样式/CanvasActionBridge 实现，确定最小可维护接口。

实现要求：
1. 稳定语义 ID、用户描述、JSON 参数 schema、当前会话/模式/选择/账户/文档上下文、可用性及共享 execute 处理器。当前能力可动态枚举；添加后续能力不应修改意图判断逻辑。
2. Notes 会话通过有界工具循环或已有共享 agent 路由调用能力，保留普通撰写和预览语义。不再以 standalone 无工具路径错误拒绝内置操作。用户文本和文档内容保持信任边界。
3. 实际覆盖本轮组合操作：当前文档 PDF 导出；全笔记或选定嵌入组件主题设置（包括易方达）；组件顶栏显示/隐藏。未选择组件时可通过全笔记的明确范围定位；模糊目标不能擅自修改其他会话。样式必须保存并反映在导出内容中。
4. 目录同时覆盖至少一种 Research/Canvas 现有动作与一种普通客户端 UI 命令，证明目录不是导出专用接口。编写 inventory 说明已接入能力及未来接入点，不能声称目录外功能已可用。
5. 请求 ID/去重、防止旧会话执行、每次执行前核验当前作用域、取消、结果 receipt（成功/待用户交互/取消/失败/不可用）及实际导出路径。未知保存路径可复用原生保存对话框，用户给定明确本地路径可正常保存。执行失败应真实说明原因。
6. 让按钮与会话复用底层处理器，避免重复的主题/导出实现。不得添加只针对用户句子的关键词分支。
7. Focused RED/GREEN 测试验证目录注册/schema、组合执行、上下文及参数校验、重复请求、取消、会话切换、未选择组件整篇操作、实际样式持久化、普通笔记生成保留和失败不假报成功。完整可执行原生测试由控制器在集成后执行。

文件所有权：可修改 Notes generate/service/editor/export/context、通用 registry/adapters、相关 types/styles 和新聚焦测试；不得修改 Global Constraints 中控制器专有文件。若必须触及专有文件，先向控制器提出接口请求。不要嵌套启动 sub-agent。

交付：实现及聚焦验证、中文本地提交、文档 inventory，报告精确 SHA、命令/结果、架构边界、原生验收调用方法与剩余问题。不要构建共享客户端或操纵用户笔记。

## Task 2: 集成后的真实客户端验收

由控制器在 Task 1 审查通过后执行。先完成笔记挑战当前变更的聚焦验证和提交，再按 integration-20261019-05 门禁整合干净来源。实际 merge 完成且验证干净 SHA 后才按本地 runbook 构建 --verify，无公证/上传/版本变动。

在专用验收笔记验证组合调用、单独能力、错误上下文、取消；检查实际 PDF 文件、主题和顶栏，真实原生 UI 与持久化结果相互对照。禁止覆盖用户正在编辑的《夏夜观荷》。保留 UI 打开并形成可追溯验收记录。未通过则继续修复，不得仅凭测试/模型自述宣告完成。
