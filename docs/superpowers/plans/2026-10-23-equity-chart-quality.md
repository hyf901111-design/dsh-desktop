# 研报图表分析质量与官方 Logo 实施计划

用户授权按专业判断优化单调的柱状图、补充折线和历史业绩回溯，并指定官方 SVG 替换右上角 Logo、删除“投资研究”。本轮沿用正式出版名、易方达色和默认 HTML/PDF 交付；不等待额外方案选择。

## 设计与证据边界

- 先选择图要回答的问题，再选择图形。多期趋势使用折线，规模与同比使用明确双轴组合图，同频两期对照可保留柱图，精确加总的变化使用瀑布算术桥。
- 原 packet 与 v3 验收冻结保留；v4 扩充官方年报支持的五年收入/成本/经营现金流、可比期间归母实绩。若历史会计政策重述缺可绑定证据，舍弃不同比较点，不伪造连续可比序列。
- 历史业绩回溯指披露实绩，不代表预测命中率或投资策略回测；没有真实预测与完整价值桥时不画假 DCF/折现价值图。
- chart.kind 缺省 bar 保持兼容；line 至少三个严格升序同频点、系列一致语义；combo 仅同期间 CNY 柱加成功同比 ratio 折线，明确左右轴；waterfall CNY 同范围，start+各 steps 精确等于 end，显著标注算术桥不是因果归因。
- 新受控 periodDifference 算子仅同指标/CNY/同范围/相邻年度同比期间 a-b；结果期间为较新期，保留旧 difference 同期限制，用于收入和成本变动算术桥。
- 使用指定 SVG 原字节、原色、原比例、白底；不因文件名“白色”而重染实际深蓝/青色路径。只读固定内置 asset，加入引擎 hash，用户输入不能选择资产路径。

## 工作划分

1. 数据：新增官方原件/TSV/定位/哈希及 v4 研究包，保留原51事实/52计算，独立 Decimal 与原件视觉核验。
2. 图表与品牌：离线 SVG line/combo/waterfall、单位刻度/零线/标签/来源/明细、目录预算，正式封面官方 Logo；聚焦红绿回归与真实打印。
3. root：periodDifference 与资产指纹，技能 v1.3.0 规范及报告交付回复的数字复述约束，集成/真实工具链/逐页视觉与原生验收。
4. 独立审阅：期间、范围、重述、轴和刻度、瀑布闭合、缺口诚实、HTML/PDF 一致性。
