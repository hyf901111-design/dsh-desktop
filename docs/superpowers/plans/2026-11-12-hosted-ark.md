# 方舟托管模型与探索额度

- 在独立功能 worktree 上实现。沿用后台 c253f6c93 的 D1 额度模块和迁移；客户端只读自己的 5 小时与周余额。
- 独立 Worker 复用账号鉴权，固定上游与模型目录，密钥通过 Secrets 注入。登录不构成套餐授权；另有显式的服务端账号允许名单。流式文本与生图先预留后结算，缺少可信用量时保留预留。现有搜索、专业数据源沿用各自的鉴权路由。
- 桌面主进程使用已有会话转发，向运行时发放本地、随账户代际撤销的访问凭据。模型通过运行时目录注册，退出时撤除。图片由现有工具调用，复用附件呈现。
- 探索登录态增加 5 小时、周额度卡；入口按实际百分比单次生长，支持键盘焦点及减少动态效果。无余额数据不显示圆环。
- OpenViking 用独立用户 Key 及固定 HTTP 协议；只有满足隔离和内容授权时同步。Agent Evolve 的公开连接器范围不含 DSH，不能把 CLI Key 注入客户端或仿冒其他 Agent 运行时。
- 聚焦验证 Worker/D1、客户端运行时、探索交互和类型；保留隔离证据，真实客户端集成按项目手册处理。
