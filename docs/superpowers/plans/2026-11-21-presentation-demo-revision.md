# 第七个演示用例交互修订

目标：按用户给定流程完成评论实时同步、右侧发送与三秒执行展示、图表原位切换、标题慢速改写、逐字稿选段优化以及回到第一页放映。

约束：沿用现有演示编辑功能分支及未验收批次；图表八个数值、原布局与易方达蓝色保持；只跑直接相关验证；本地提交，不发布或晋升 main。

- [ ] 评论输入逐次发布到原生对话引用，只更新该引用所拥有的文字。
- [ ] 四轮对话均显示预设的执行说明、等待 3000ms，再提交文稿改动；发送必须经过原生按钮。
- [ ] 将框选图表原位转换成横向条形图，保留母版、坐标、大小、原始数据和配色。
- [ ] 演示标题引用改写后，在备注中模拟拖选一段，通过右侧输入修改意见并仅替换选段。
- [ ] 返回第一页，鼠标点击放映，以首页放映结束。
- [ ] 运行内容保存、原生输入引用、示例对话路由及编辑器渲染的聚焦验证，创建中文提交。
- [ ] 更新原批次交接，构建签名本地客户端，复播并检查实际画面、持久化及三秒节奏。
