# 浏览器工作区应用实现与验收

> 使用 executing-plans 在本会话执行。按用户要求自主判断，不增加方案确认环节；只做直接相关检查。

目标：实现 Figma 76 页的 01–22 状态，在中间工作区提供真实浏览器，复用右侧原生对话。

设计来源：https://www.figma.com/design/Jkyr5rMvgM8GNH6E68xnqd?node-id=4502-368737
基线：b46dc4dc5；独立功能分支 codex/feat/browser-app-figma-20261109。

架构：独立 Electron WebContentsView 与浏览器分区、受信任主窗口 IPC；主进程持久化普通标签、收藏和历史，隐私分区仅内存；预加载 DOM 界面复用 WorkspaceSurfaceHost，原生会话视图复用研究右栏和输入草稿。原会话智能体浏览器能力保留。

验收关注：远端页面不能调用客户端 IPC；切换会话/页面不串写输入；晚导航不覆盖新标签；无痕数据不落盘；下载路径及权限变更可追溯；悬浮层不被原生网页盖住；关闭/重开保留正常标签与草稿。示例网页与历史内容来自真实访问，不将 Figma 虚构资料作为产品数据。

源码阶段验证：34 项直接相关检查、2 项渲染流程、类型检查通过。独立 Electron 43.4.0 / Chromium 150.0.7871.224 原生夹具通过真实输入、导航、查找、缩放、静音、标签固定、普通/无痕隔离、下载暂停继续、Blob 导出、并行同名下载、PDF、工作材料、主窗口关闭重开与外来 renderer 拒绝。网络页面为受控 HTTPS 合成页面，不能替代最终用户客户端验收。

独立审查发现的窗口重开、隐私下载记录落盘、重复 URL 打开、权限显示漂移、中文 IME、Blob 下载与并行同名下载问题已修复并覆盖回归。Browser 插件未提供，渲染聚焦测试使用既有 Playwright；原生视图另由 Electron 测试验证。未运行全功能测试。

决策：Cookie/站点数据按所选时段访问过的站点清理；Chromium 的缓存清理接口按所有时间执行，界面已明确说明。下载文件、收藏和工作材料保留；隐私下载记录不落盘，关闭最后隐私标签后移除记录。正式共享客户端仍待集成构建及真实窗口验收。
