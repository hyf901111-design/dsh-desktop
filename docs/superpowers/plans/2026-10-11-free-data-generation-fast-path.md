# 免费源工作台生成优化

用户要求：组件生成更快、更可靠，同时在真实客户端创建三类每分钟刷新的金融工作台。

此前客户端三次生成中，模型先读取大量规范、查询数据、复制数组、再创建静态快照，随后重复查找组件及绑定刷新；首轮规划约需5.8–10分钟。部分面板复制了父会话记录，未取得自己的取数凭证，无法建立可信绑定。

## 实现

- 常见报价表、报价指标、加密指标、量价、日K线、新闻使用声明式 `panel.publicData`。父会话只确定标的、模板和范围，宿主使用固定内置适配器取得真实数据、生成已核验的映射并保存刷新绑定；不启动逐卡模型。
- 每个来源任务独立持久化、取消和报告状态，全局最多同时执行4个来源任务；仅绑定成功才完成。未改需求的重试复用原来源配置，修改需求则走正常生成流程。
- 原生K线模板的日期范围控件采用交易日语义，直通K线仅支持腾讯日线；Kraken分钟记录使用量价模板，避免错误的日期范围标签。
- 指令按需选择，默认免费源说明精简，详细目录仍可读取；无关示例代码不再进入每个面板指令。遵守用户选择的模型和推理等级。
- 维护已有的来源权限、禁止联网、用户指定来源、共享画板限制、失败保留数据、真实报价时间和币种规则；未支持的来源或模板保留正常流程。
- 修复“不新建卡片”等请求误显示生成规划；失败/停止规划可关闭，避免临时卡片占用画布。

## 聚焦验证

- 7个直接相关测试文件：259项通过、1项已存在的旧HTML面板提示长度断言跳过；类型检查通过。
- 额外运行旧工作台测试遇到26项失败，变更前880cd440同样26项失败，名称一致；其中22项为旧前端菜单夹具锚点失配。未将这些测试称为通过，不扩展为全功能修复。
- 五类直通模板使用真实来源查询/映射成功，整体1.45秒；此数字只代表取数及模板准备，不代表用户发送到客户端完整显示的耗时。
- 取消、来源失败、绑定失败、10组件并发限制、重启恢复、精度/未知时点、权限、重复计划及原配置重试均有针对性检查。
- 客户端加密复测发现模型在面板与publicData两层重复填写intervalMinutes，原严格工具schema导致额外重试。现在明确声明兼容字段，统一规范到publicData；相同值可接受，冲突值拒绝，用户只手动刷新指令仍优先。
- 实际客户端耗时、首轮结果和分钟刷新在集成构建中继续验证，记录在金融分钟验收报告。

本次只构建本地测试版，不变更1.1.3版本号，不上传或推送，不晋升未经用户接受的集成提交。
