# Homebrew 分发 Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans in this session. 用户要求常规选择自行执行，不追加确认流程。

**Goal:** 提供公开可用的 Homebrew Cask 和可靠的后续版本同步流程。

**Architecture:** 独立公开 Tap 复用固定版本 Cloudflare 安装包，发布工具先核对正式 feed 再生成 Cask，提交和推送作为最后的软件源提升步骤。

**Tech Stack:** Node.js、YAML、Ruby Cask、Homebrew、Git。

**Spec:** `docs/superpowers/specs/2026-10-27-homebrew-design.md`

## Global Constraints

- 仅支持 Apple Silicon、macOS 12+；保留客户端内更新及用户数据。
- 不构建、升级或替换共享客户端；不改线上 feed 和版本号。
- 只运行直接涉及的测试和 Homebrew 验证；每项完成后作中文本地提交。
- 功能 worktree 保留交接记录，遵守多会话集成手册。

## Review Focus

- 尚未上线或已回滚的版本不得推进 Tap。
- 本地包与线上 feed 的 SHA-512 或大小不同不得写入 Cask。
- 不可变资源缺失、网络失败不得写入 Cask。
- 低版本或同版本不同 SHA-256 不得覆盖现有 Cask。
- 已手工安装的 App 不可静默覆盖；迁移时先退出、备份并移走旧 App，不使用可能将旧 App 误登记为新版的 `--adopt`。
