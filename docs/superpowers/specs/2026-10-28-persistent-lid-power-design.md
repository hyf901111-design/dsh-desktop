# 合盖继续运行：记住设置与一次授权

用户修正了第一版“本次运行有效”的行为：开启后应记住选择，后续打开客户端自动恢复合盖防休眠，正常启动不再提示密码。退出或异常结束仍恢复系统睡眠。

## 实现选择

保留 macOS 12 基线，以首次管理员授权安装签名的受限原生 LaunchDaemon。辅助服务不使用 sudoers、网络或任意命令接口，只执行固定的 pmset 电源操作。服务常驻待机；客户端通过独立租约表明运行意图，租约结束时释放本服务持有的电源覆盖。

客户端仅在手动开启且服务缺失/需修复时显示一次系统安装授权；自动启动恢复严禁弹授权框。macOS 13 起提供的 SMAppService 不覆盖当前 macOS 12 基线，暂不改变最低系统版本。首次授权由用户手动完成，不自动操作安全授权窗口。

## 行为

- 两个偏好均持久化，默认关闭；读取旧版偏好保留普通防自动睡眠设置。
- 合盖设置只有在辅助服务确认当前租约且 pmset 回读生效后才显示开启。设置失败、取消授权及保存失败均明确反馈；恢复启动失败保留用户意图供修复，不伪装成功。
- 退出释放租约但不删除辅助服务、不清空开启偏好，下次启动无提示重新获取租约。
- root 服务校验租约文件所有者/权限/类型、主进程 UID、PID 启动时间、正式应用 identifier 和签名 Team ID；心跳30秒过期即释放。
- 已有外部 SleepDisabled=1 借用而不关闭。服务在改变0→1前写入 root 恢复日志，崩溃/重启先恢复后接受租约；过热、低电量和外部状态漂移停止当前租约。
- 主进程只对已确认的 `system-changed`、原 owned active 模式且已保存/当前请求仍 ON 的情况做有界恢复：先确认停止旧租约，再以 `start(false, true)` 原子申请空位中的新 nonce。遇到新客户端接管则停止，不能覆盖其他租约。恢复不安装或授权，不修改 helper2 或 native 的旧 nonce 停止策略；瞬时未确认、外部借用、安全停止均不触发该流程。
- 自动恢复在60秒内最多2次、间隔至少15秒；失败或密集冲突即停止自动尝试并记录诊断，保留保存偏好。关闭、退出、安全事件同步撤销当前意图；在读取状态、等待停止和等待重新获取时均重查意图/安全条件，迟到的租约立即释放。
- 正常关闭发布同一签名进程的 release 租约；服务完成恢复和日志清除后以相同 PID/nonce 回执。客户端收到精确回执才删除租约，避免把尚未处理获取请求前的旧 idle 状态误认成已恢复。恢复失败保留日志及待释放标识；崩溃后的过期租约不阻塞新客户端握手。
- 自动安全停止只暂停当前运行，不清空已保存的选择；条件恢复后的下次启动仍按原偏好恢复。多用户同时运行的连续保活不是本次范围；全局锁避免重复认领，客户端实际回读漂移并报错，不宣称多个用户之间存在引用计数保护。
- 安装时先复制到 root 私有暂存目录，再核验签名与 SHA-256，避免用户可写来源的检查/使用竞态。没有运行用户目录下的提权脚本。

## 协议与文件

辅助程序 `/Library/PrivilegedHelperTools/com.evanarts.sherlock.power-helper`；服务 `com.evanarts.sherlock.power-helper.<uid>`。

`/Library/Application Support/EWork Odyssey/Power/<uid>` 由 root 拥有，内含 root status.json、recovery.json；其 leases/ 子目录由对应用户拥有，session.json 是唯一租约入口。

租约 `{version:1,pid,started,token}`，started 为 C locale 的 ps lstart，token 为32位小写hex。状态 `{version:1,servicePid,mode,ownerPid,token}`；mode 为 idle/active/external/safety-stop/system-changed/error。没有可执行参数、动态路径或 shell 命令协议。

## 验证边界

聚焦测试验证跨重启偏好、自动恢复不弹授权、安装一次、租约接管/释放、撤销授权与失败回滚；原生策略用隔离后端验证，不修改主机电源。检查原生编译、打包资源、签名和实际客户端 UI；真实首次授权、合盖和重启效果必须区分用户报告与自动观察。
