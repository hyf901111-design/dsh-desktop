# 对话原生生图

用户澄清：不需要专用界面。用户在对话中提出生成或修改图片需求，助手自动调用具备生图能力的模型，并在同一会话返回图片。加载阶段参考 ChatGPT：图片占位卡片持续展示流动渐变，完成后原位显示真实图片；失败、取消、历史中断结束动效，无假进度。

通过内置 image_generate 工具执行，与普通对话模型独立，直接调用图片 provider，不依赖技能、Bash 或用户填写工具名。默认已配置 OpenAI Image 2.6 Flare，Sunburst 可选。参考图来自当前会话已有的用户附件或已生成图片；凭据通过已有 credentials 服务解析，不向前端、模型或日志输出。生成结果进入原生持久附件存储，沿用图片查看及下载能力。provider 接口为未来内置模型留扩展点，不嵌入开发者密钥。

完成标准：真实对话自然语言触发，图片原位返回；占位卡片在执行详情折叠时也可见；尺寸正确，浅深色和减少动态效果适配；取消/失败/历史重开状态正确；拒绝跨会话图片引用、未知模型和任意 URL；请求幂等、有限响应、无自动付费重试。运行聚焦测试、独立代码审查、本地集成构建和真实客户端验证。
