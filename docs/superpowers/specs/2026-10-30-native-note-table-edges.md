# 笔记原生表格：边缘控制与自然尺寸

依据本轮用户提供的飞书空表格及 Root 实际体验：细网格、紧凑空表、顶部与左侧窄条选择整列/整行、左上图标进入整体菜单。用户明确要求移除可见的行列编号、尺寸摘要和“这里可以编辑”之类说明。

本次范围仅为原生笔记表格的尺寸和操作呈现。表格仍使用 BlockNote/ProseMirror 的真实单元格、表头、行列操作、拖动与 Yjs 保存/Undo；Space 与右侧请求仍由同一原生 executor 处理，不引入组件子任务或额外模型请求。

- 空表每列自然宽度100px；3列约300px，8列按正文可用宽度收敛。已有完整列宽保持原值，多列达到原生35px下限后只在表格内部横向滚动，不扩展正文或页面。
- 无常驻文字工具栏。左上为34×24图标入口；行列边缘保留无障碍名称，无可见“行/列”标签、编号或占位文字。点击边缘形成原生整行/整列蓝选区，保留原生菜单和行列拖动。
- 整体菜单含标题行/标题列、适应正文、均分列宽、数值宽度、当前行/列操作和删除表格；菜单使用笔记本身的暗浅主题与 top layer，外点、Escape、模式/owner切换关闭。
- 整体宽度手柄改为右侧10px热区，鼠标显示左右调整光标。预览和控制边缘同步移动；普通整表拖宽不无意超出正文，已保存的超宽表不被自动改写。双击边缘适应正文，键盘方向键/Home、菜单数值输入仍可用。
- 拖动只预览，不在每帧写文档；松手一次提交，Escape/失焦/丢失capture/模式退休回退预览。单次Undo和保存重开保留真实宽度与单元格。
- 本轮不改变 Main协议、生成逻辑、研究组件/行情组件或 SDK 安装脚本；唯一 executor 改动是空表初始列宽采用同一自然尺寸 helper。

验收：旧14个真实 Browser 用例全部保留对应语义（文字入口调整为图标/菜单入口），补充薄边缘真实CellSelection、空白紧凑表格、暗色菜单、表头/删除Undo、实时宽度抓手及双击适配等用例；再核对原生操作与组件顶栏直接点击的相关 Browser 回归。功能 worktree 不构建或替换共享客户端，最终签名包与 Native 验收交由 Root。
