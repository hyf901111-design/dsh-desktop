# 正式研报版式与文件命名

用户要求学习本地《宁德时代_研报样例.pdf》的封面格式及内容、内页板块与数据要素，继续使用易方达配色，并让 HTML/PDF 都以正式报告名命名。沿用用户已经明确的自主执行授权，不再次发起方案/确认问题。

## 参考与取舍

已目视封面及二十一页总览；独立代理继续审查各类代表页。样例封面是投研摘要页：日期、公司代码/行业、观点主标题、正式报告副标题、报告类别；约七成宽投资要点、三成宽评级/基本数据/小图；页底全宽盈利预测与估值摘要。内页采用目录/图表索引、编号论点标题、正文、两栏专题图表、三表摘要、来源及风险声明。参考原文、数字、评级、作者和机构身份不进入本次茅台研究证据。

选择在现有确定性 HTML 引擎上新增正式出版版式，HTML 与 PDF 共用内容；不另建独立 PDF 内容模板。固定 A4、白底、易方达深蓝/蓝青，内页较紧凑的中文正文字体、三线表、图号/表号、单位/期间/口径/来源就近显示。PDF 保持当前隔离认证打印服务。目录与图表索引使用可点击锚点；实际 PDF 页码由打印宿主生成，不生成推测的目录页码。评估真实分页目录的可行实现后再决定是否增强。

## 出版结构

1. 摘要封面：两层标题、公司/代码/行业/研究日/财务基期、投资要点、研究状态、可核验基础数据、历史收入/利润小图、核心财务摘要与预测状态。正文不复制长技术ID。评级只展示“未评级”及当前估值资料状态，不自动生成投资建议。
2. 目录及图表索引：完整研究十个范围及财务附录均可导航，图表连续编号。
3. 正文：保留证据支持、推论、假设、反证和观察条件；可用宽度足够时并排展示相关图表，打印避免不可分割的大容器。论点、图/表标题不与内容孤立。
4. 财务摘要：按合并/母公司、全年/中期及资产负债时点清楚分列，盈利、现金流、资产负债三组；不存在的项目不补零。未完成预测与估值明确说明缺口，不用历史数伪装预测。
5. 证据、计算、披露原文、来源与局限附录保留追溯能力；正文与封面所有金额/比例均来自同次事实或计算。

## 数据与命名接口

`report.title` 保持可核验的观点大标题；新增可选 `report.publication:{companyShortName,reportType,industry}`。`reportType` 仅支持“公司研究报告”“财报点评报告”“公司研究简报”，缺省由 full/brief 选择公司研究报告/公司研究简报。shortName、industry 为有界纯文本，不代表新事实认证。封面要点复用 summary，允许可选 label，并沿用数字模板校验。

新增 `publicationMetadata(packet)` 返回 `{companyLabel,reportType,financialPeriodLabel,reportName,fileStem}`。期别从 financialAsOf 推导：年末为年报、半年末为中报、季末为一季报/三季报，其余为截至日期。正式 `reportName=公司（代码）期别报告类型`，`fileStem=reportName_研究日期`，经 NFC 与文件名清洗、有界 UTF-8 截断及短摘要避免冲突。观点标题与正式报告名分开。HTML `<title>`、封面副标题、PDF 元数据及页眉以正式报告名为准。

CLI 实际输出 `fileStem.html` 与 `fileStem.pdf`，辅助 JSON 保持稳定名。`run.json.artifacts` 记录逻辑类型到实际 basename，仅含实际产出；`outputs` 仍以实际 basename 为键保存摘要。可信工具据显式映射返回绝对入口，成功须核对所有必需类型、摘要及 PDF 字节记录。拒绝绝对路径、分隔符、符号链接、额外类型及不同 stem 的双报告。取消/失败仅允许有界扫描恢复唯一安全报告入口，不能凭扫描认定成功。

## 验收与边界

聚焦覆盖出版元数据、正式命名、HTML 结构/转义/引用、数据摘要的期别/范围、动态产物映射及完整性/取消回归；不跑全功能测试。用现有茅台原件扩充封面及叙事结构，不联网虚构行情或模型。生成最终 HTML/PDF，逐页目视封面、目录、内页图表/三表、来源和声明；确认正式文件名、无裁切/孤标题/重复表头错误。独立审阅后走本批次严格后继交接、精确集成、`./script/build_and_run.sh --verify` 本地构建与真实任务默认双格式验收。保持版本 1.3.5，不接受/晋升 main 或公开发布。
