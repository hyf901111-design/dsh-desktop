# 笔记挑战模式实现规格

来源：用户明确要求实施 session「设计笔记挑战模式运行机制」`01a15c32-e6f2-7703-84e3-aa84d44b23de` 的最终方案；已读取全部用户修订、原始一致预期 MD 和 Figma 高保真上下文。

- Figma：`Jkyr5rMvgM8GNH6E68xnqd`，页面 `2703:365319`；完整暗色 `2707:375608`，五档选择器 `2704:366242`。最终版本 `comment-action-group-v8-20261021`。
- 保持当前笔记/右侧对话外壳。五档为关闭、宽松、标准、严格、抬杠，默认关闭，逐笔记保存。280×112 浮层仅当前等级、介绍和五档吸附滑条；不增加单独开关、挑战记录或检查详情入口。
- 用户日常只在正文划标及评论出现时感知运行，不弹处理进度，不抢焦点。宽框在原文右侧显示评论；窄框点击标记后在附近显示气泡，无连接线。
- 评论使用中性灰，引用原文、AI挑战身份、问题类型和描述。操作顺序 AI优化、查看依据（仅有实际依据）、弹性空白、已解决。没有更多菜单、回复入口或撤销按钮。已解决移除评论展示和划标，保留持久化去重历史。
- 回复框常驻评论底部，连续自然换行；发送在框外右侧，单行居中、多行底边对齐。长线程只滚动消息区，输入区可见。AI优化和回复结果继续同一线程；显式优化才替换原文，替换前校验当前锚点，保留未改动文字格式。
- 依据在客户端右侧独立“挑战”页签显示，内容只能是已取得的原文对照、计算或数据；没有实际依据不显示按钮。关闭评论不解决问题。
- 默认增量审查。停笔/最短运行间隔：宽松15/60秒、标准5/30秒、严格3/20秒、抬杠3/15秒；跨段最短间隔10/5/3/2分钟。无正文变化不重复。排除输入法组词、光标、样式、评论、组件心跳与保存。每篇单任务，合并最新变更；离开/后台/关闭/人工写作时取消或暂停；返回只补变化。
- 不把未完成句子当语病；局部结果可与相关原文比对。长文分批，覆盖范围真实，不宣称全文通过。结果返回重新校验原文和上下文，过期结果不落评论。已解决且正文未变的同问题不重复。
- 研究报告只有可靠抽取证券代码、基准日、预测年度、核心指标、数值、单位时才进行一致预期专项。仅 infodb/TYDW_FILESYNC/ASHARECONSENSUSDATA；滚动口径仅按需要使用 ASHARECONSENSUSROLLINGDATA。数据源不可用明确留缺，不伪造、不引入其他源。
- EST_DT≤报告基准日的最近快照优先；缺失回退最新只能作为“事后参考”，不判历史报告当时有错。EPS元，净利润/主营收入静态表万元，亿元→万元×10000。C1区间外、C2相对中值偏离>20%（明确行业配置才改变）、C3超过1个标准差且机构≥5；少于5家不做C2/C3强判断。零/负中值、空字段、不同口径需降级。同比方向与上/下修方向分开，不能混算C4；目标价不在范围。所有等级证据门槛相同。
- 复用 BlockNote/Yjs 原有评论、保存、草稿、撤销和账户隔离；不改写既有正文、组件或历史。仅相关聚焦验证和中文本地提交；功能worktree不构建共享客户端，经批次集成后按本地测试手册构建，不发布/推送/晋升main。

接口：`src/shared/notes-challenge.ts` 定义前后端交换的有界请求、问题、依据与结果；运行时 JSON只接收这些字段。模型输出不被视为查询证据，金额/阈值/日期比较由程序执行。
