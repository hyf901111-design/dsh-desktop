# 协作看板日历

用户明确要求：日历组件可在协作看板使用，各个有编辑权限的成员都能创建日程，全部有查看权限的成员能看到日程。原截图的“个人日历暂不支持协作看板”错误必须消除。

沿用原生日历组件界面、日期选择、搜索、添加、编辑和完成交互。共享日程以看板和日历组件为边界，走已有持久协作链路；不写入创建人的个人日历文件，也不自动发布个人已有日程。个人日历行为保持兼容。查看权限成员可浏览，编辑权限成员可创建及管理共享事项，成员退出/权限撤销后遵守现有看板门禁。

同一日历两位成员并行首次添加、后续添加、断线重连和重启不应静默丢失任一成功保存的事项。使用稳定事项ID与细粒度持久化，不用全数组替换制造丢失更新。共享界面文案说明共享保存状态；不能仍写“本机保存”或以失败冒称成功。现有个人提醒不得复制给其他成员；共享提醒如不能复用，应清楚界定而非伪造提醒成功。

只修改本功能，保留现有用户内容与草稿，不发布公开客户端、部署云端、调整版本或推送。签名客户端从受管集成分支构建，功能worktree不能构建共享客户端。开发完成只做相关聚焦验证，中文本地提交。
