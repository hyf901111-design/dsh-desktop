# 日历工具组件

用户授权规划、设计并开发；沿用现有组件库、组件最小尺寸和三种看板主题。

## 产品行为

- 组件库新增“日历”。默认月历＋所选日期事项；日期有事项标记，支持上月、下月、今天、日期跳转和搜索。
- 事项支持标题、日期、全天／时间、备注、每日／每周／每月重复、完成、编辑和删除。重复事项按当天完成，编辑和删除作用于整个系列。月末重复日期在无对应日期的月份跳过。
- 提醒支持准时、提前 5／15／30／60 分钟、一天和自定义分钟。全天事项按当地 09:00 提醒，明确显示；日期／时间采用保存的 IANA 时区。显示下次提醒时间。
- 保存即时写入本地，独立于模型与 MCP。提醒在客户端运行（含后台、其他会话）时由主进程触发系统通知；睡眠／重启恢复后补发尚未处理的提醒，重复日程合并为最近一次，避免通知轰炸。
- 所属 session 显示可关闭的“日历提醒”提示，日历内保留最近提醒记录。系统通知点击打开所属 session 并定位日历。通知不依赖当前组件是否挂载。
- 关闭应用期间不能即时推送；提醒设置处简洁说明“客户端运行时提醒”，恢复启动后补发。系统通知不可用时仍保留会话提示。
- 事项为本机个人数据；共享看板暂不开放此工具，避免误以为其他成员同步收到事项与提醒。
- 常规宽度为两栏；窄且有足够高度时上下排列，窄矮或最小高度优先显示所选日期和可滚动事项。编辑窗口居中于当前可见画布，窄窗口内可滚动，不撑破组件。
- 中文／英文切换即时生效，事项原文保留；复用看板色彩、字号、焦点反馈和无描边更新反馈。

## 技术边界

- 新增独立 `calendar-tool` 容器类型，不扩充金融数据类型，也不改变生成型 HTML 日历。
- 主进程原子 JSON 存储、串行变更、输入验证、持久化提醒收据；刷新间隔 5 秒，恢复时立即检查。
- 时间转换拒绝不存在的夏令时日期时间，重复时区时间稳定选择第一实例；每次变更重新计算下一提醒。
- 删除／完成取消对应提醒；组件移除后暂停提醒，数据保留以支持撤销。
- IPC 只开放给可信主窗口，校验 session 与组件存在；错误不清空已有事项。
- 只运行本次相关测试和类型检查，提交中文本地提交。构建真实客户端，跳过公证，不发布、不升版、不推送。

## 验收

原子保存和重启恢复；日期／重复／夏令时；后台提醒和去重；完成与删除取消；点击通知导航；窄／最小尺寸和三主题；英文切换；真实客户端创建、编辑、完成和收到提醒。

## 2026-10-11 界面与易用性修订

按用户的“简单直观易用”反馈调整现有组件，不增加新的设置层级：

- 默认月历与当天事项并排；日期使用 28px 圆形选中态，行高 40px，避免随组件高度拉成长条。内容高度不超过 220px，或内容宽度不超过 480px 且高度不超过 400px 时，切为可选日期的事项列表，保留事项阅读空间。
- 顶栏统一 16px SVG，事项内辅助图标 12px；图标与按钮点击区域独立，关闭和加号居中。
- 月历、周视图、待办和提醒记录统一到视图入口；周视图按实际发生日期分组；待办列出未来 30 天各事项的下一次未完成安排。
- 搜索收为顶栏图标，按需展开输入框并自动聚焦；关闭图标或 Esc 返回原视图。返回视图与搜索状态在本机保存，切换会话后仍可正常退出搜索。提醒记录从视图菜单进入，取消月历侧的重复待办区。
- 内容左右边距 12px，与组件顶栏对齐；常规两栏间距与事项侧内边距均为 16px，事项复选框 16px，文字间距 8px。日期与时间使用等宽数字，事项标题、元数据与备注沿同一左边线。紧凑事项按行对齐复选框、标题与右侧时间。
- 顶栏控件统一 28px 高；窄宽度保持单行，避免按钮换行侵入星期栏。输入框只保留外层焦点描边；编辑弹层采用 16px 内边距与 12px 字段间距。
- 快速添加只输入标题，旁边明确显示可选保存日期；默认为全天、不重复、不提醒。切换待办时从今天开始；需要提醒或备注时打开完整事项编辑。
- 双击日期新建，方向键导航日期；选择日期、月份和视图在本机恢复，不混入看板布局。
- 系统或会话提醒定位清除搜索条件；仅修改重复事项文字保留过期待补发的提醒和已处理状态。
- 用户事项原文保持不变；中英文、浅色／深色／易方达及通用最小组件尺寸保持支持。
- 日期圆环与事项标记保留 3px 间距，使用固定尺寸的圆点；周视图选中仅突出日期圆形，星期保持清晰可读。待办文字按钮保留内边距，悬停背景不会贴住文字。
- 搜索激活后展示已保存事项，输入关键字再筛选；不受此前所选日期限制。弹窗字段对齐，全天时禁用并弱化时间框。
- 组件库统一复用选中后滚动规则：未选中时滚动画布，选中且内部在该方向可滚动时才消费滚轮，到达边界继续滚动画布。行情图仅在选中时缩放，编辑弹窗可正常独立滚动。
