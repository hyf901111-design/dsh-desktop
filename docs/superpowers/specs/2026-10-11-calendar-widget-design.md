# 日历工具组件

用户授权规划、设计并开发；沿用现有组件库、组件最小尺寸和三种看板主题。

## 产品行为

- 组件库新增“日历”。默认月历＋所选日期事项；日期有事项标记，支持上月、下月、今天、日期跳转和搜索。
- 事项支持标题、日期、全天／时间、备注、每日／每周／每月重复、完成、编辑和删除。重复事项按当天完成，编辑和删除作用于整个系列。月末重复日期在无对应日期的月份跳过。
- 提醒支持准时、提前 5／15／30／60 分钟、一天和自定义分钟。全天事项按当地 09:00 提醒，明确显示；日期／时间采用保存的 IANA 时区。显示下次提醒时间。
- 保存即时写入本地，独立于模型与 MCP。提醒在客户端运行（含后台、其他会话）时由主进程触发系统通知；睡眠／重启恢复后补发尚未处理的提醒，重复日程合并为最近一次，避免通知轰炸。
- 所属 session 显示可关闭的“日历提醒”提示，日历内保留最近提醒记录。系统通知点击打开所属 session 并定位日历。通知不依赖当前组件是否挂载。
- 关闭应用期间不能即时推送；提醒设置处简洁说明“客户端运行时提醒”，恢复启动后补发。系统通知不可用时仍保留会话提示。
- 事项为本机个人数据；共享看板暂不开放此工具，避免误以为其他成员同步收到事项与提醒。
- 常规宽度为两栏，窄宽度上下排列；最小高度只显示所选日期和可滚动事项，月历通过切换显示，编辑采用锚定弹层，不撑破组件。
- 中文／英文切换即时生效，事项原文保留；复用看板色彩、字号、焦点反馈和无描边更新反馈。

## 技术边界

- 新增独立 `calendar-tool` 容器类型，不扩充金融数据类型，也不改变生成型 HTML 日历。
- 主进程原子 JSON 存储、串行变更、输入验证、持久化提醒收据；刷新间隔 5 秒，恢复时立即检查。
- 时间转换拒绝不存在的夏令时日期时间，重复时区时间稳定选择第一实例；每次变更重新计算下一提醒。
- 删除／完成取消对应提醒；组件移除后暂停提醒，数据保留以支持撤销。
- IPC 只开放给可信主窗口，校验 session 与组件存在；错误不清空已有事项。
- 只运行本次相关测试和类型检查，提交中文本地提交。构建真实客户端，跳过公证，不发布、不升版、不推送。

## 验收

原子保存和重启恢复；日期／重复／夏令时；后台提醒和去重；完成与删除取消；点击通知导航；窄／最小尺寸和三主题；英文切换；真实客户端创建、编辑、完成和收到提醒。
