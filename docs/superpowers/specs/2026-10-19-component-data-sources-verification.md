# 组件来源与自动更新验收记录

## 已完成的行为

- 生成组件的底栏状态可点击，打开对应组件的“数据与自动更新”。已登记多个兼容来源方案时，来源区域变为下拉框；单一来源保留说明框。
- 原生自选股、个股行情、市场指数、新闻、公告共用该面板，可以保存来源、更新频率和暂停状态。日历沿用现有行为。
- 更换来源立即取数；仅修改频率不触发重复取数。仅手动和暂停状态停止周期请求；隐藏页面暂停请求，返回页面仍遵守暂停状态。
- 来源切换保留上次有效内容。个股报价成功但 K 线失败时，保留原图表、成交量单位及原图表来源，失败信息在面板中说明。
- 来源入口和面板操作不会触发画布拖动或删除；Escape 关闭后还原入口焦点，Tab 保持在面板中。笔记中的同类组件也能访问设置。

## 内置备用方案

| 组件 | 备用取数 |
| --- | --- |
| 自选股、个股行情 | 新浪沪深北报价及可用 K 线；Yahoo Finance 港美报价和历史 |
| 市场指数 | 新浪境内指数；东方财富已核对标识的全球指数；部分走势和其他指数使用明确标注的 Yahoo Finance |
| 新闻 | 与默认方案相反的新浪/东方财富接口；新浪关键词模式过滤最近返回的真实标题和摘要 |
| 公告 | 巨潮资讯；先精确查询交易所及证券身份，再获取对应公告与官方 PDF 链接 |

备用 K 线不支持所选复权时会明确提示，不冒充复权数据；巨潮备用公告不支持美股。新浪关键词新闻受最近资讯列表覆盖限制，可能无匹配项。生成组件必须登记完整、兼容的请求及字段映射方案，不将多个依赖请求拆成可替换来源，也不会凭空替换用户的通联数据。

## 本地客户端验收步骤

1. 在研究看板点击生成组件左下角的更新状态，确认标题属于该组件；多方案组件能切换完整来源，单一方案只显示来源说明。
2. 从组件库添加上述五类组件，点击左下角来源。选择备用方案并修改频率，确认请求使用新来源、刷新内容保留真实来源；关闭并重新进入后选择仍保留。
3. 暂停更新或选择仅手动，离开并返回看板，确认不恢复周期请求；立即更新仍可用。
4. 在同一标的下模拟备用历史失败，确认有效旧图仍显示，来源与成交量单位不被新来源覆盖。

本功能保存在独立 feature worktree，尚未构建或替换共享客户端。按项目集成手册创建集成批次后，才能构建客户端交给用户验收。
