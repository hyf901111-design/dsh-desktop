# 研究画板渐进式上下文设计

状态：用户已确认按本方案实现（2026-09-03）。本文件记录已批准的聊天设计，不扩大到发布或替换共享客户端。

## 产品行为

- 研究模式发送非空文字/图片时，若画布无选中节点且输入框没有显式组件或文件引用，默认把当前会话画板全部节点作为可检索资料集；屏幕外节点也包含。
- 显式选择或固定引用优先，沿用现有引用逻辑；普通对话、空输入、其他研究会话不受影响。
- 输入区显示轻量“当前画板 · N 项资料”，可展开目录及关闭本次自动上下文。不生成 N 个内联标签。发送成功恢复默认，失败保留用户选择和草稿。
- 每次发送绑定不可变资料快照；后续编辑、队列等待、切换会话不能把本轮换成另一个画板。文件冻结路径及版本，读取时版本已变化则报告不可用，不读取新版本冒充旧快照。

## 三层披露与预算

1. 目录：标题、类型、来源、概况、可用状态；初始目录受预算限制，完整目录通过分页获取，明确总数/剩余量。
2. 证据：按当前问题的标题、实体、正文关键词相关性展开段落、表格行或图谱节点；中文分词使用本地字符片段与短语，不引入联网模型/向量数据库。宽泛总结与“继续”不独占一份资料，采用多来源轮转。
3. 工具：`research_context_list`、`research_context_search`、`research_context_read`，只读当前调用者会话及指定快照；参数是快照 ID/组件 ID/分页游标，不接受任意文件路径。

首轮最高约 6,000 估算 token，32 KiB UTF-8 硬上限；可用上下文窗口较小时按 8% 下调。单次工具结果最高约 1,800 估算 token，12 KiB 硬上限；一个快照后续工具结果累计最高 12,000 估算 token/64 KiB。估算不是精确模型 tokenizer，界面不声称精确。所有标题、目录、工具包装文字都计入预算；返回明确的截断/剩余游标/预算耗尽状态。不得为凑满预算填充无关正文。

首轮元数据/证据预算约 25%/75%，证据按相关性与来源多样性分配。PDF/Markdown 等相同正文去重并保留别名，派生总结保留来源关系，不视为独立的重复证据。矛盾结论与失效边界不因立场不同被剔除。空白、失败、未授权节点只提供状态。已存网页正文只表示已捕获内容，未证明完整时不标为全文。

## 安全和接口

- Electron 主进程从 `ResearchCanvasStorage` 读取当前会话节点。文件必须通过现有预览授权注册表解析，绝不使用网页/模型传入的路径。网页使用已授权组件捕获的 `sourceText`，不传 Cookie/Token，不主动访问网页。
- 可信主窗口 IPC `research:context:capture` 产生会话绑定的随机 `captureId`，冻结节点资料；浏览器子框架不能调用。主进程提供仅环回、私有 bearer token 的只读桥；密钥只通过环境传给本地 Harness，不能暴露给 renderer 或模型。
- Harness `POST /sherlock/research-context/prepare` 接受 `{sessionId,captureId,query}`，验证当前父会话存在，取得私有桥的快照并调用上下文索引。返回 `{snapshotId,totalSources,initialSourceIds,initialContext}`。这里不把未展开全文放入会话提示词。
- 读取工具从 `exec.agent.session.id` 获取所有者，不能信任模型指定的 sessionId。快照在运行时内存保留 2 小时，最多 20 份/32 MiB；过期、预算耗尽或重启后失效明确报错，不回退到别的资料。主进程 capture 保留 10 分钟并有数量/总字节限制。
- 所有来源文字置于明确的不可信资料边界；工具结果标注节点 ID/标题/页或段落。忽略资料内改变任务、索取敏感信息等指令。
- 文件文本复用现有有界提取能力（文本/PDF/PPTX），未支持的格式或图像明确标为需要专用读取，不能伪造正文。读取有大小限制、版本校验、取消信号与超时边界。

## 兼容与失败处理

保留 V1 显式引用协议；仅增加可选 `canvasContext` 字段，允许没有显式引用而只有自动上下文。消息投影隐藏内部序列化元数据，展示简洁画板来源标记。准备资料失败时明确提示，不静默发送一个看似含画板但实际没有资料的请求；用户可关闭本次自动上下文继续。同一快照复用于已准入发送重试，不因队列消息取错画板。创建新研究首次发送仍保留研究模式。

## 验收

仅运行直接相关测试：排序、预算、分页、去重、文件版本变化、会话隔离、私有桥/IPC 权限、真实工具执行、无选择自动发送、显式引用优先、空输入、失败恢复、关闭本次上下文、已授权网页正文与 UI 提示。最终执行类型检查、构建与依赖补丁可重放验证；功能 worktree 不构建/替换共享 Sherlock 客户端，不发布、不改版本、不推送远端。
