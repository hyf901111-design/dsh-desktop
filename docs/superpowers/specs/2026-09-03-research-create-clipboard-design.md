## 基于所选创建

选中一个或多个组件后，功能栏新增「基于所选创建」。弹层列出带类型图标的来源和多行提示词，空提示不能生成。确认时冻结来源，仅基于该选择按相关性读取真实内容，包括已授权网页和文件，不把整个画板无差别塞进模型。来源读取失败需要明确反馈，禁止只凭标题假装阅读全文。

按提示词生成一个独立新组件，覆盖原生 Markdown、表格、图表、KPI、思维导图；保留来源快照与提示词，可取消、重试。原组件不变；新组件放到所选区域附近空位并选中，不自动联动源组件。复用安全 JSON 渲染，不执行任意生成脚本。

## 画板剪贴板

剪贴板优先级：Sherlock 组件快照 > 系统文件 > 图片 > 文字。文字直接成为可编辑组件，不调用模型；图片持久存储；PDF/PPTX/DOCX/XLSX 等复用现有安全预览，不支持的格式显示明确文件卡片而不是空白。

组件复制保留内容、名称、尺寸及相对布局，粘贴生成新 ID 与独立资源，不携带原画板授权 token、运行任务或自动刷新。跨画板可用，原文件/原组件删除不破坏副本。文件复制进入应用管理的持久存储，授权在目标 session/node 下重新签发。系统剪贴板只持有可校验的本地快照引用，不能用伪造文件路径扩大访问权。

画板焦点下 Cmd/Ctrl+C/V；编辑器、输入框与网页内部原生复制粘贴不被劫持。右键组件「复制」；右键已选择集合复制集合；右键背景「粘贴」，无可用内容置灰。右键粘贴位置固定为点击世界坐标，键盘粘贴用画板内最近鼠标位置或视口中心，重复粘贴错开。一次粘贴对应一次撤销/重做。异步导入时切换画板、撤销、存储失败要清理未提交授权且不写入另一画板。
