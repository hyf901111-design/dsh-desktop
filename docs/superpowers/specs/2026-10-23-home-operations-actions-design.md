# 首页四个快捷入口

## 用户要求

右侧研究看板、笔记、演示文稿、研究报告卡片接入实际操作。看板进入当前会话的研究看板 Tab（原生 id `research`），笔记进入原生 `notes` Tab。PPT、研报先平滑返回输入区，插入对应内置技能的真实标签和预填提示词，中间预留主题空白并选中，供用户直接输入；不自动发送。

## 实现选择

复用原生会话、Tab 与技能输入链。已有会话不新建；无会话时通过原生工作区入口物化一次会话，缺工作区则明确提示。不给侧栏新建按钮模拟点击，不伪造笔记浮层。通过窄页面事件桥让原生上下文负责会话准备和 Tab 选择，不新增 main IPC。

PPT 使用 `builtin:efund-ppt-maker`（PPT制作助手），研报使用 `builtin:ework-equity-research`（研报写作）。每次实时获取 catalog revision，再由既有 `createSkillUseBridge` 复核 detail、启用与可用状态；通过 `SessionInputShell.insertReference` 插入真实标签，再用 `insertText` 插入文本。禁止写 textarea.value 冒充模型草稿或纯文本技能标签。

预填主题为六个全角空格 `「　　　　　　」`，焦点选中空白范围。PPT 文本说明公司品牌与模板、内部汇报、观点大纲、可编辑 PPT；研报文本说明研究框架、事实/判断/假设区分、来源日期、风险缺口及 HTML/PDF 交付。提示词采用当前界面语言。原有文字、附件和引用保留到模板后，以空行分隔。重复点击同一已有技能且正文非空时不叠加模板、不覆盖已编辑主题。

## 边界

保留已验收的卡片样式、灰彩融合、透视、渐变、轮播和区域运动。只增加点击业务、处理中防重与可见错误反馈。原输入节点不重建，原生权限/审批/只读限制不绕过。技能停用、会话/账号切换、草稿 revision 变化、离页及卸载须拒绝过期结果；失败不发送消息。仅运行直接涉及的聚焦测试和类型检查，中文本地提交；功能工作区不构建共享客户端。

## 验证

真实原生输入 shell 验证标签语义、提示词、选区、原草稿/附件/引用与不发送；浏览器验证四卡接线、先完成回输入运动再填入、快速重复点击和错误可见；导航测试验证原生 Tab 及无会话物化/取消。最终通过独立原生客户端操作验证，按多会话集成手册交接。

等待技能目录前捕获原生草稿 draftRev；目录或技能详情延迟时若用户已编辑（即使又改回同文），拒绝本次预填，保留草稿与焦点。
