## Design and scope

- Figma file Jkyr5rMvgM8GNH6E68xnqd，已读取设计上下文与截图：2973:374140、2973:375240、2985:369586、2985:369662。只实现主题卡片相关界面，不混入该session其他输入框示意图。
- 运营区域顶部为无背景的“快速开始 / 主题壁纸”页签；仅文字颜色区别选中状态。右端32px全局明暗模式按钮，18px太阳/月亮图标。
- 标准宽度780px，header32px、间距12px、五列三行，列/行gap12px。预览约146.4×78px、radius7，名称上间距8、12px/18px。当前选中预览仅1.5px轮廓，无勾选图标。
- 内容和功能为当前原生15壁纸，保留规范key、渲染器、动态与原子持久化。不得用Figma图片替换现有壁纸，也不得引入新远程资产。
- 规范key：default、berber、vghodki、jarrick、lowfreez、accelbia、boz、shashidhar、haseeb、kirian、splines、antiquue、crt-warp、dither、koi-pond。显示名称采用Figma中英文映射，key不重命名。
- 主题壁纸页才按需生成全部预览，并缓存和释放临时渲染器；不增加15个常驻动画/GL实例。背景仍由唯一原生owner渲染。
- 页签/主题选择在明暗模式切换期间保持。明暗按钮必须调用真实native ThemeRuntime，持久化全局设置并同步右屏/portal，不得只改body属性。
- 移除旧底部壁纸dock及专用保留空白/滚轮分支。保留输入/运营两个完整区域的自然切换，不恢复对方部分透出的旧交互。
- 窄宽/矮高不产生局部滚动条，不截断预览或名称；紧凑布局仍保留15个可点选预览、可辨认标题、合适内容比例。普通研究/笔记主题不被覆盖，已有会话草稿与guide actor实例保持。
- 运营小卡单独提交已完成9dbc3eb6：仅quick ±9°/720px，72ms阻尼，独立不同的动态渐变增强，无描边/光斑/配图生长/文字模糊/圆角露边；大卡原幅度保持。
