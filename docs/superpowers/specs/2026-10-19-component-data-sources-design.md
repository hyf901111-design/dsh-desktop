# 组件数据源切换与更新设置

## 目标
用户点击组件底栏左下角的数据/来源状态，打开该组件的“数据与自动更新”。面板中的来源区域在存在兼容来源方案时提供下拉选择，并保存刷新频率。组件库中的自选股、个股行情、市场指数、新闻、公告各提供一个实际取数的备用方案；日历保持现有行为。

## 现有链路与边界
- 生成组件由 ComponentDataRefresh 保存请求和字段映射，宿主调度刷新；workbench 页脚目前为不可点击 div。
- 内置 financial-widget 通过主进程固定 HTTPS 适配器取数，现为固定 60 秒刷新。旧组件保持兼容，配置只增加可选字段。
- 多个相互依赖的请求是一个完整来源方案；只有请求、映射都明确的方案可以互相切换。
- 保留布局、选中状态、图表交互、组件标识及上次成功数据；不同标的不能混用旧数据。

## 方案
1. 抽出共享设置面板视图，生成组件与 financial-widget 使用同一标题、来源框、频率、时点、暂停/立即更新操作。
2. generated binding 可登记 sources（id、name、requests、mapping）；默认方案与备用方案均须校验工具权限、连接及模板。配置 sourceId 时重新授权校验、取消旧请求并用新 revision 隔离旧响应。原有请求数组不被误当成下拉选项。
3. financial-widget 增加 dataSource(default/backup)、refreshMinutes(0..10080)、refreshEnabled，可序列化并随组件保存。默认仍按 1 分钟可见刷新；暂停和仅手动不启动周期请求。更换来源保留旧结果直到新结果成功，部分失败保留相应数据段及其来源。
4. 备用行情：沪深北报价/沪深 K 线使用新浪公开接口，港美报价/K 线使用 Yahoo Finance；全球指数使用已核对标识的东方财富公开指数表及明确标识的可用来源。备用新闻使用与默认不同的新浪/东方财富源；备用公告使用巨潮资讯。来源不支持的市场/复权须明确返回不可用，不能生成模拟数据或标错来源。
5. 主进程保留固定 HTTPS origins、请求/字节上限、账户隔离、失败保留数据及缓存隔离；不在渲染器执行来源脚本，不接受任意 URL。
6. 左下角可通过鼠标与键盘打开面板，操作不触发画布拖动/删除；关闭面板恢复触发器焦点。深浅主题及窄窗口可用。

## 验证与交付
只执行直接受影响的绑定引擎、公开金融适配器、组件契约、设置界面及笔记/研究交互测试和 typecheck；使用真实浏览器检查来源/频率保存及旧数据保留。实际备用接口做只读取数探针。按项目约定创建中文本地提交和交接卡；本次不从功能 worktree 构建共享客户端，不自动合并或发布。
