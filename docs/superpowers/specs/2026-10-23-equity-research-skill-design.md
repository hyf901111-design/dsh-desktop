# 内置研报写作能力

用户已要求按研究结论直接接入 EWork，首批为研究规范、证据台账和确定性计算；报告使用易方达配色，完成后启动本地客户端测试。实现沿既有技能/会话文件区接点，不新增独立研究服务或接管客户端模型。

## 用户体验

新增默认启用、可在技能管理中关闭的“研报写作”内置技能，slug `ework-equity-research`，支持技能列表选择和固定斜杠入口。明确撰写证券/公司研报时加载该技能；简单行情或普通写作继续原有路由。取数沿用当前可用金融连接和用户资料。

技能组织研究任务、保存公开原文快照、登记事实与假设、执行校验与计算、写作并渲染。输出 `report.html`、`evidence.json`、`calculations.json`、`validation.json` 和 `run.json`，保存在当前会话工作区。HTML 可阅读和打印，PDF在用户需要且本机打印能力可用时生成；首批不承诺通用 PDF 自动导出或全链路 Excel 模型。

## 计算与证据边界

EWork 已带 Node，首批命令行工具使用 ESM 与标准库，避免给用户增加 Python/Claude Code 安装门槛。采用 LEDGER 的职责分离和可复算约束，独立实现经过聚焦验证的首批计算，不引入其完整多角色 harness 或已知有缺陷的估值模板。

每个事实绑定指标、期间、合并/归母范围、单位、十进制定点原值、source ID 与行列证据。本地快照必须真实存在并核对 hash；quote/value/metric/period/scope/unit 均匹配指定证据窗口，不能仅判断数字在整页出现。来源登记与快照一致性不等于外部真实性或 PDF 提取正确性，报告保留该差异及人工复核状态。未知指标、缺少数据或歧义列给出明确诊断。

金额和比例先做十进制精确运算；比率、差额、同比和合计由程序产生。可选 FCFF 情景 DCF 明确预测为假设，校验折现率和永续增长关系、现金/债务/金融资产/少数股东/股本逐项桥接。首批采用固定年末年期折现，显式展示该局限，不称为滚动交易日目标价；没有经核验行情不生成现价空间或评级。金融子公司混合口径需要人工处理，不能用勾稽通过替代估值经济判断。

## 文稿和配色

数字断言通过模板引用事实/计算 ID 插入；不允许文稿自由填入未经核验的财务数字。数据表、图表、来源、假设和复核状态从同次运行生成。HTML转义所有外部文本，不执行输入代码，不依赖外部脚本或 CDN。

配色固定为易方达深蓝 `#005096`、中蓝 `#0078B4`、青 `#1EB9E1`、标题青 `#00BEE6`，浅蓝 `#B3EBFF`，正文 `#3C3C3C`、线灰 `#C1C6C8`，黄色 `#FFC819`只作单一强调。采用颜色规范，不把研报伪装成已获公司专业签发的正式报告。

## 集成和验收

在独立 feature worktree 开发，相关代码中文提交，按仓库交接及 integration 工具生成可追踪候选。功能 worktree 不构建共享应用。用户已授权本地测试；只执行 `./script/build_and_run.sh --verify` 与包检查，跳过公证、不改版本、不推送或发布。候选用户验收和晋升状态如实保留，不伪造 accepted。

聚焦验收包括：内置技能发现/选择/关闭；错期错指标和单位混淆拒收；大额数值精度；无行情不产生评级；非法路径与 HTML 注入；同一输入复算一致；易方达配色和真实研报可读性；实际包包含新技能及脚本；真实客户端主界面与技能入口可见并保持打开。
