# 输入框语音输入

空闲且没有可发送文字、引用或附件时，原生共享 InputBar 的禁用发送箭头改为白色圆形波形按钮。点击聚焦同一受控编辑器并调用现有 macOS Speech 引擎。首页、普通对话、研究右栏和笔记均复用此入口；运行任务的停止按钮和仅附件发送沿用原行为。

录音时按钮左侧显示小胶囊，内含由真实 level 事件驱动的波形和方形停止按钮，无悬浮录音对话框。累计 partial/final 只替换当前拥有的语音片段，保留手动编辑、不重复追加、不自动发送。文本非空时恢复发送箭头；录音中空内容仍禁用发送。

提示条以 240ms ease-out 从发送按钮旁向左展开，平滑改变宽度、透明度和轻微位移，发送按钮位置固定。音频 level 或识别状态更新不重播放入场动画，也不触发新的录音请求。停止立即隐藏可访问状态、禁用交互，保留 240ms 收起；快速重开及卸载清理退出 timer。prefers-reduced-motion 下即时展开/移除，音量条仍由真实事件更新。

只有 Esc 或点击胶囊停止按钮手动结束录音；Esc 消费当前按键，保留草稿。普通按键、打字、编辑器或窗口失焦继续录音。录音期间普通 Enter、Cmd/Ctrl+Enter 均防止发送且不中断录音；Shift+Enter 和 IME 提交沿用原编辑行为。发送箭头在录音时禁用，提示“请先停止语音输入再发送”，停止后恢复发送。导航、视图隐藏、输入会话变更、附件、运行任务、非可信输入和卸载继续撤销录音身份并拒绝迟到结果。

每次录音维护最后受控 draftRev、累计 ASR 文本和自己拥有的语音片段锚点。可信原生 input 事件只认领同一编辑器实际 value 对应的受控草稿变更；其它来源的 setDraft 继续清理。片段外的用户插入/删除移动锚点并保留原文；片段内部编辑冻结用户稿，从旧累计转写的稳定末尾定位新语音增量，再于稿尾重新锚定，重复 partial/final 不重复追加。早期 ASR 标点变化仍可用稳定末尾对齐。若早期改写连稳定末尾也无法找到，保留用户稿和原保护基线，暂不应用该歧义结果；随后恢复稳定对齐时只写新尾部，避免旧词复活。

IME 组合期间暂存最新 ASR（final 保持终态），等 compositionend、最终可信 input 和原生 composingRef 稳定后再合并并自然结束。组合结束的短暂稳定期内新结果继续覆盖旧 pending，避免旧 partial 回退草稿。手动编辑不抢回焦点；音频写入前记录选区，只有同一 draftRev、输入仍聚焦且没有新交互时才跟随或恢复原选区。任意按键、鼠标和窗口 blur 清理待执行光标工作，自然 final 后的待执行工作也受此保护。

安装器支持从既有 v1 运行时升级：按唯一成对标记、紧邻的原生导出、已知运行时声明顺序及有效 JavaScript 识别自有区块，不要求旧函数内容等于新实现；区块外各原生 UI hook 仍逐个严格撤销。缺标记、重复标记、未知版本、损坏语法、移动边界或 hook 漂移均拒绝。使用历史 8d17d49 原始安装器生成旧 entry，验证官方入口升级及双重重入，不清空安装目录。

采用单一 ResearchVoiceController 的临时 composer owner 和独立受 trusted main-window 保护的 startComposer IPC。composer 不调用 setActive、不覆盖 research 注册；期间暂停 Fn，结束后基于当时 research 注册重新计算 Fn。保留窗口/主帧/前台校验、唯一 native request ID、单一 capture 和既有权限策略，不修改原生 Speech 引擎。初次启动仍要求可信主窗口处于前台；composer 激活后跨窗口失焦仍接收识别，可信停止可在后台送达。Research Fn 仍沿用原先前台校验及权限宽限。

选择在 InputBar 内接入输入机器及生命周期，而不是 DOM 文本覆盖或新的录音引擎：前者可保留草稿、引用、笔记输入路由和发送仲裁；后两者会破坏受控状态或引入重复麦克风所有权。

约束：不启动真实麦克风、不构建/替换共享客户端、不新增依赖、不运行全量测试、不推送或合并。UI 证据为生产输入机器/渲染器加假语音桥的隔离 Chromium；原生麦克风与真实客户端验收留给集成。
