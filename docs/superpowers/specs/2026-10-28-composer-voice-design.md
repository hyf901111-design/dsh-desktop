# 输入框语音输入

空闲且没有可发送文字、引用或附件时，原生共享 InputBar 的禁用发送箭头改为白色圆形波形按钮。点击聚焦同一受控编辑器并调用现有 macOS Speech 引擎。首页、普通对话、研究右栏和笔记均复用此入口；运行任务的停止按钮和仅附件发送沿用原行为。

录音时按钮左侧显示小胶囊，内含由真实 level 事件驱动的波形和方形停止按钮，无悬浮录音对话框。累计 partial/final 替换当前录音草稿，不重复追加，不自动发送。文本非空时恢复发送箭头；录音中空内容仍禁用发送。

提示条以 240ms ease-out 从发送按钮旁向左展开，平滑改变宽度、透明度和轻微位移，发送按钮位置固定。音频 level 或识别状态更新不重播放入场动画，也不触发新的录音请求。停止立即隐藏可访问状态、禁用交互，保留 240ms 收起；快速重开及卸载清理退出 timer。prefers-reduced-motion 下即时展开/移除，音量条仍由真实事件更新。

任何按键、编辑器失焦、鼠标停止、导航、视图隐藏或卸载立即停止接收结果并取消录音，保留已有文字。普通按键保留原行为；用于停止录音的首个非 IME Enter 不得顺带提交；IME 提交不被吞掉。开始/取消/再次开始、IPC 延迟、手动编辑与末尾回调竞态均按精确请求身份及 draftRev 处理。

组合快捷键按真实修饰键 keydown → Enter 的序列处理：修饰键先停止录音时，暂记其编辑器，仅拦截同一手势的首个非 Shift/IME Enter。修饰键 keyup、首个其它按键、失焦、鼠标操作、新录音或卸载清除此状态；无录音时的普通 Cmd/Ctrl+Enter 沿用原生行为。

窗口 blur 也清除修饰键手势状态与待执行光标更新，以处理系统吞掉 keyup 的情况；回到窗口后普通 Enter 可正常发送。该监听不取消录音、不改变主进程对权限面板的授权宽限，并在输入会话卸载时移除。

安装器支持从既有 v1 运行时升级：按唯一成对标记、紧邻的原生导出、已知运行时声明顺序及有效 JavaScript 识别自有区块，不要求旧函数内容等于新实现；区块外各原生 UI hook 仍逐个严格撤销。缺标记、重复标记、未知版本、损坏语法、移动边界或 hook 漂移均拒绝。使用历史 8d17d49 原始安装器生成旧 entry，验证官方入口升级及双重重入，不清空安装目录。

采用单一 ResearchVoiceController 的临时 composer owner 和独立受 trusted main-window 保护的 startComposer IPC。composer 不调用 setActive、不覆盖 research 注册；期间暂停 Fn，结束后基于当时 research 注册重新计算 Fn。保留窗口/主帧/前台校验、唯一 native request ID、单一 capture 和既有权限策略，不修改原生 Speech 引擎。系统权限对话的窗口失焦沿用 main 控制器既有授权宽限；编辑器 DOM 失焦仍立即停止。

选择在 InputBar 内接入输入机器及生命周期，而不是 DOM 文本覆盖或新的录音引擎：前者可保留草稿、引用、笔记输入路由和发送仲裁；后两者会破坏受控状态或引入重复麦克风所有权。

约束：不启动真实麦克风、不构建/替换共享客户端、不新增依赖、不运行全量测试、不推送或合并。UI 证据为生产输入机器/渲染器加假语音桥的隔离 Chromium；原生麦克风与真实客户端验收留给集成。
