# 研究画板渐进式上下文实施记录

2026-09-03。功能分支 `codex/feat/research-progressive-context-20260903`，基于本地 main `806487f9bda011f7ba36691c51bd3e613cb3a5fb`。

## 行为

- 研究模式、没有选中节点或手动引用时，发送文字/图片默认参考当前会话画板；屏幕外节点也在资料范围内。普通对话及手动引用逻辑保持不变。
- 输入框显示“当前画板 · N 个组件”，展开只显示标题和状态；可以仅对本次关闭，成功提交后恢复默认。准备失败保留文字/图片并提示，不偷偷发送无资料请求。
- 首轮是精简目录和按问题挑选的证据；目录约占25%，正文约占75%。特定主题排除无关正文，整体总结覆盖多个来源。相关性采用本地中文短语/字符片段与英文关键词，非额外模型或向量检索。
- 模型通过三个只读工具继续列目录、检索、分页读取。来源快照与会话绑定，后续画板修改不改变本轮资料；来源状态、截断和来源关系保留。
- 首轮完整协议最多6000估算token/32KiB，包含包装与分隔符转义；已知小上下文按8%下调。工具单次1800估算token/12KiB，快照累计12000估算token/64KiB。估算不是精确tokenizer。
- 网页复用组件已授权捕获的正文，不传登录凭据。文件必须经过已有授权表解析，并在提取前后校验真实路径与版本；未支持或不可读的资料不伪造正文。

## 已知边界

- 本次没有构建/替换共享 Sherlock.app，没有改变0.7.8版本，没有发布或推送远端；功能分支保留等待接受后的集成和真实客户端测试。

- 快照有有效期和内存上限；应用重启或过期后须重新发送，不静默读取变化后的资料冒充旧快照。
