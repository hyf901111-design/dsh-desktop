# EWork 网格研究工作台实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan inline. Steps use checkbox syntax for tracking.

**Goal:** 将 Research 的无限画布替换为 OpenBB 风格的有限宽、纵向滚动网格工作台。

**Architecture:** 保留现有工作区模型、组件渲染器、生成/刷新/导出通路。添加纯网格布局引擎及前端补丁；工作区仍保存真实组件几何，网格状态按 session 持久化。交互以完整布局事务提交，取消时还原全部让位组件，readonly 不写入。用独立 worktree 完成开发，再通过 Plan A 集成批次构建本地测试客户端。

**Tech Stack:** JavaScript patch modules, existing React page runtime, Vitest, Electron.

## Design contract

- 40 列；25px 行高、10px 组件间距、12px 外侧留白；卡片 4px 圆角，34px 顶栏、12px 标题和16px线性图标。深色背景 #151518；浅色沿用等价的明暗层次。
- 拖动顶栏重排、右下角改变跨度。实时碰撞让位，180ms 过渡，松手纵向紧凑补位并吸附最近格位。
- 组件工具可以在已有组件区域拉框，格位预览与拖动共用碰撞引擎。链接和语音点击时立即在末尾创建组件。
- 底部四工具保留；旧选中浮动操作栏取消。思维导图详细度、总结提炼、基于所选创建进入组件更多菜单；多选时作用于当前选择。
- 左上刷新按钮使用真实刷新通路；hover 显示成功刷新记录的相对时间和日期时间。没有记录时显示“尚未刷新”，不得伪造时间。
- 保留各组件真实内容、数据来源与交互；调整尺寸时内容区域重新布局，表格/长文允许内部滚动，HTML/图表继续收到真实容器尺寸。
- 旧几何首次转换保持阅读顺序及相对宽度；不删除内容。取消操作、撤销/重做、重新打开需要保存一致布局。
