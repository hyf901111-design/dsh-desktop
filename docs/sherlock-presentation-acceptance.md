# 演示应用本地验收

## 易方达原稿与可选版式

用 Microsoft PowerPoint 打开技能附带的 `efund-template-v6.pptx` 并导出 PDF。在一个独立测试会话中导入同一文件。按幻灯片的实际顺序切换并截取中央画布，以相同宽度逐页并排检查 46 页。单独用两份源母版检查图库的 16 个 V6 版式和 30 个骨架版式。两组页数相同，验收对象不同。

| 场景 | 通过条件 |
| --- | --- |
| 中文目录 | 第 7、15、19、34、43 页显示 01 至 07 全部内容。末行位于画布和页脚之内，页脚无占位符。第 7 页的文稿页码为 6。 |
| 内容页 | 标题栏、品牌标识、页脚对齐；表格保留逐行高度和各边分隔线；母版无法被点选删除。 |
| 原生图表 | 扇区、折线、柱、数轴和系列数与同页原稿对应。第 24、26 页的左轴显示收益率，右轴显示成交额，横轴显示月份。第 24 页的图例与刻度分开，图下的数据来源完整可见。第 17、24、26 页的组合图在导出后仍包含对应系列类型。 |
| 可选版式 | 46 个版式都能加载对应母版、建立可编辑占位符。封面日期在白底上可读，封面和内容标题遵循各自母版的字体、字号与内边距。含页码的版式上移一页后页码减一，导出文件保留原生数字字段。反复应用版式保留用户正文、图表数据和备注。 |
| 历史文稿 | 以旧版保存的模板重新进入会话，无需重新导入。逐对象核对迁移资格，已经修改过的图表或表格保留用户版本。 |
| 读写往返 | 改标题、备注、单根柱颜色并保存重开。导出后使用 PowerPoint 打开，重新导入时核对对应页、元素、系列、数值与颜色。 |

## 编辑交互

从侧栏和顶部演示页签进入。编辑对象时验证直接修改文字颜色、文字高亮、填充与描边。分别检查线宽、实线、虚线、点线，验证插入直线和箭头以及撤销、重做。正文编辑、备注选区和图表标记需要在右侧输入框中产生可混输的引用，确认修改只作用到被引用的对象。

对空会话和已有文稿分别锁定。锁定后页面导航和查看仍可用，工具栏、备注、删除快捷键和对话写入均不能修改文稿。检查修订号，退出再进入后检查锁状态；解锁后执行一次实际保存。
