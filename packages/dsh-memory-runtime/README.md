# EWork internal memory runtime

Private Cordis plugin. `apply(ctx)` installs `createMemoryRuntime(ctx)` with the actual `agents`, `sessions`, `sessionPersistence`, and `llm` services. The optional `tokenMeter` service prices the actual transient message against the prepared model's context capacity. It registers no user-callable tools.

`EWORK_MEMORY_BRIDGE` is a JSON object containing an authenticated `http://127.0.0.1:<port>/` URL and token. The desktop bridge owns identity, shared-session exclusion, project binding, enable flags, content versions, manual locks, provenance, deletion barriers, usage state, and persisted pending captures. Endpoints are POST `/recall`, `/validate`, `/usage`, `/capture`, `/attempt`, `/commit`, `/failure`, and `/pending`. Missing bridge configuration makes `apply` a graceful no-op so unavailable secure storage cannot veto normal app startup.

The rc.7 `agent/request-context` extension runs after `request/header` logging and immediately before the original `preparedCall.stream`. Pre-step selection is revalidated at this final boundary and after usage recording. A stale selection is retrieved again; repeated changes omit memory and record a generic warning. Actual request messages are immutable copies; transient text is never appended to a session event, request header, or compaction surface. The authoritative block includes priority and no-permission framing and is limited to 1,200 UTF-8 bytes including that framing. When the whole block cannot fit, it is omitted and a visible warning is recorded; no fragment is silently truncated. Existing history compaction and overflow retry continue to own the original history.

Completed parent turns first pass `sessions.flush`, then `sessionPersistence.readFrom` confirms the exact durable `turn/end`. Only direct `source.kind=user` text and assembled assistant text enter capture; plugin context, raw chunks, tools, subagents and plugin-only scheduled turns are excluded. Short confirmations may include the immediately preceding completed turn, while staying candidates. Leading exact source excerpts and extraction framing together are bounded to 4,000 UTF-8 bytes. Model extraction uses the turn's routed provider/model, an independent `purpose=memory-extraction` request, no tools, and at most five candidates. Evidence must be an exact substring of the named user event. The serial queue makes one extraction call with at most one retry. Errors expose only fixed generic messages. Commit writes are never retried.

Startup recovery consumes only persisted `/pending` captures and reauthorizes each via idempotent `/capture`. It does not scan old sessions. Each model dispatch first reserves a durable attempt via `/attempt`; the bridge preserves the maximum-two budget across restart. An ambiguous reservation is never replayed. Already dispatched conversation requests cannot retract previously sent memory. Unknown adapter capacity falls back to the bridge byte budget; known capacity uses tokenMeter (or conservative byte estimation if absent).

Focused verification: `npx vitest run test/memory-runtime.test.js`. Tests use real Cordis services, a copied and patched installed AgentLoop, a token meter, an authenticated local HTTP bridge, and a real JSONL backend. Canonical dependencies and shared clients are untouched.

Each turn carries the owner epoch, scope epoch and project ID obtained before enqueueing. Capture rejects stale or absent anchors; durable recovery can only renew authorization for pending jobs with the same stored scope. A disabled use switch returns a quiet request without memory.
