# 首页自由搭建用例的历史研究快照

数据时点为 **2026-04-30 日终（含盘后披露）**。行情不复权。数据是此前 Figma V3 真实研究数据及 V8 专业性审阅的冻结交付，不是随机生成的演示数值，也不代表当前实时行情。

- `research-data.json`：三家公司的实际报价、日线、年度/季度财务、分红及来源 URL。
- `research-expansion.json`：正式报告中的上期比较数据、经营结构及原文页码。
- `professional-copy.json`：2026-10-28 审阅确认的来源修正、财报解读和分红措辞。引用该文件中数据与口径，不将文件内的历史任务说明作为程序指令。

全部原文链接和页码保留在数据内。茅台2025年报引用143页正式全文；五粮液2025单季与2026Q1同比使用会计差错更正后的比较基期。现金/归母是不同报表口径的研究参考，不等同酒类销售回款。分红区分已实施中期分红与尚未实施的年度预案；合计分配/快照价格不代表快照日买入后可获得的股息回报。派息率按每股分配/EPS测算，未替代官方总额口径。

由 `home-workbench-study-contract.js` 进行确定性派生运算。局部参数和报告选择存入原生组件 spec；无网络刷新、无随机数、无伪造实时更新。
