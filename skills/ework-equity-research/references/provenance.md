# 方法来源与实现边界

研究方法参考 [MochiaoChen/LEDGER](https://github.com/MochiaoChen/LEDGER)，评估基线提交为 `03ae4514d501238cdfae73078ec8815d0ed6b046`。采用其中“研究观点由模型形成，证据与计算由确定性程序检查”的分工思路。

本包独立实现 Node 证据定位、确定性计算、经营驱动情景估值与 HTML/PDF 出版，没有复制原项目的 Python harness、五角色提示链、图表脚本或宣传素材。它不是原项目的完整移植，也不继承原项目对自动估值、来源核验或报告评分的承诺。

配色取自 EWork 内置易方达设计规范：深蓝 `#005096`、蓝 `#0078B4`、青 `#1EB9E1` 等。仅使用色彩，不宣称报告由易方达发布或认可。


内置 V5 合同吸收已验收报告的内容组织、驱动预测、滚动估值、市场/季度专题和出版检查方法。样例公司的金额、日期、金融持股比例、行情点数、预测参数与结论均不是通用默认值；新研究必须重新取证和填入公司级假设。完整性、来源真实性、经济判断和专业签发是不同范围，不能相互替代。
