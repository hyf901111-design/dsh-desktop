# 研究图表：用图回答问题

图表不是把表格换成彩色柱。按分析问题选择图形，所有值仍来自同次已核验事实或成功确定性计算。易方达配色、正式图号/单位/期间/范围/来源、PDF可读性保持一致。

## 数据先于图形

- 尽力核验连续多年披露，完整列示起止期间；缺少合理历史时继续找原件，不能只挑两期就声称长期趋势。
- 年度、中期、季度和时点分开。合并、母公司、净利润和归母不混用。会计重述优先采用有原件绑定的可比重述值；无法核验的点退出连线和同比，明确缺口。
- “历史业绩回溯”是已披露实绩走势。没有当时留存的预测版本、披露时间戳和统一口径，不输出预测命中图或策略回测收益图。
- 折现价值图只有在真实研究假设、现金流预测、WACC/永续增长与完整股权桥可复核时使用，不把历史经营现金流直接当 FCFF。

## 图形与合同

`kind` 缺省 `bar`，兼容旧包。title/name/label 与正文一样走数字token与来源约束。禁止任意 SVG/JS/外部图像路径。

### 折线 line

```json
{"kind":"line","title":"已披露年度盈利轨迹","series":[{"name":"归母净利润","refs":["profit22","profit23","profit24","profit25"]}]}
```

至少三个严格升序且连续相邻年度的同频期间，各系列期间对齐、单位与范围相同，每系列指标含义一致。保留真实节点，不用平滑曲线制造拐点。百分比趋势可以在明确刻度和提示下使用聚焦纵轴；不能无提示截轴夸大变化。若数据断点不可比，应分开序列或缩短可比窗口。

### 规模与增速 combo

```json
{"kind":"combo","title":"收入规模与同比","series":[{"name":"营业收入","type":"bar","refs":["revenue23","revenue24","revenue25"]},{"name":"同比（右轴）","type":"line","refs":["growth23","growth24","growth25"]}]}
```

只接受一个 CNY 柱系列与一个成功 `yoy` 比例折线系列，至少三个相同升序期间、同范围。左轴亿元从零起，右轴明确百分比与零参考，不能把毛利率/任意比率标成同比，也不能混用年度与半年数据。显示双轴本身不足以证明两组数据有因果关系。

### 可加总 waterfall

```json
{"kind":"waterfall","title":"毛利润变动算术桥","startRef":"grossProfit24","endRef":"grossProfit25","steps":[{"label":"营业收入变化","ref":"revenueChange25"},{"label":"营业成本影响","ref":"costEffect25"}]}
```

所有项目为同范围 CNY；steps 只引用成功的 `difference/periodDifference/sum` 受控金额变化，严格核对起点加所有步进精确等于终点，不用展示舍入值勾稽。允许起止为已计算的毛利润，变化分别来自同指标相邻年度。不能把不同频率/期间的数凑成桥，也不能用“其他”残差冒充已研究的归母净利润因果归因。显著写明“算术桥，不代表因果归因”；图旁保留输入/算式明细。

### 保留适用的柱图

两期同频实绩对照、少量类别金额比较仍可用柱图，从真实零起。年度和中期分图；图多并非研究更完整，不为凑图种使用饼图、雷达或装饰图。

## 出版检查

逐图检查：结论是什么、数据为何可比、轴/零线是否诚实、期间与范围是否清楚、所有关键值是否可读、来源能否追溯。线图/组合图/桥接图保存或配套精确数据明细；不能为缩小版式隐藏数值。打印与屏幕检查负值、零值、平序列、极小差额、长标签和密集点；低分辨率预览不替代真实PDF。图表索引、准确页码与正文连续图号共同生成。
