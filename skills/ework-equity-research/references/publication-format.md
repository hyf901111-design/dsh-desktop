# 正式研报封面与内页规范

本规范学习用户提供的公司年报深度点评样例的信息组织：摘要封面、目录与图表索引、论点式专题、盈利预测/估值和财务摘要、来源与声明。借鉴结构和视觉层级，不能将样例公司的数字、预测、评级、作者或机构身份移入新研究。颜色始终使用易方达蓝青；不要擅自添加公司 Logo 或专业签发标志。

## 两层标题与出版身份

- `report.title` 是本次观点大标题，例如“渠道重塑中的盈利与现金再验证”，不要只写“公司分析”，也不用工作目录或技术测试名称。
- `report.publication.companyShortName` 填来源可确认的公司简称；缺省使用 company.name。
- `report.publication.reportType` 只能为“公司研究报告”“财报点评报告”“公司研究简报”；默认 full 用公司研究报告，brief 用公司研究简报。类别不证明研究质量或专业签发。
- `report.publication.industry` 填真实研究行业；未知先核对资料。
- 正式副标题由公司、代码、财务期别和类别组成；财务期别与研究日分开。HTML 文档标题、PDF 元数据、运行页眉与实际文件名使用正式报告名，观点主标题保持独立。

作者/联系人/执业编号、机构名称和投资评级只有真实授权资料才能出现。默认显示 EWork 研究支持和待研究复核状态；不能为模仿券商封面编造资质。未核验现价和模型时显示未评级及资料状态，不能输出目标价、评级或上涨空间。

## 封面是可读的研究摘要页

A4 白底，约十五毫米页边；主内容宽约一百八十毫米。观点大标题约十九至二十一磅，摘要正文约九至十磅，颜色由深蓝承担层级、蓝青承担强调。上方排列研究日、公司代码与行业、观点主标题、正式副标题和报告类别。其下约七成宽投资要点，约三成宽研究状态/基本数据及小图；页底全宽财务摘要。

摘要复用 `report.summary`，每项可写简短 `label`，通常六至七项，以有证据的论点组织：

1. 事件与当期业绩：公告/报告期、收入与归母利润、可比同比，说明变化。
2. 核心经营逻辑：产品、量价、渠道、份额、客户或成本中真正解释业绩的因素。
3. 盈利质量：毛利、费用、税费、非经常项或经营/财务因素的传导。
4. 现金与资本：现金回笼、营运资本、资本开支、股东回报；金融业务必须穿透口径。
5. 盈利预测与估值：关键假设、估值方法与条件，缺资料则明确状态及影响。
6. 风险和反证：具体触发条件及跟踪项，不能只放泛化风险词。

所有金额、比率、股数、每股数据、报告期都用既有 token；label 也不能藏手写金融数字。正文保留展开推理和反证条件，封面要点精炼，不能将长技术原文或事实ID堆到首屏。长输入允许自然续页，不能裁切、隐藏或整页缩字。

## 封面数据要素与口径

| 要素 | 正确呈现 |
|---|---|
| 研究状态/评级 | 有资料才估值；默认未评级，清楚区分支持、部分资料、未建模 |
| 基本数据 | 公司代码、财务基期及可核验资产/负债/每股等；行情必须带真实报价时点，不冒充研究日现价 |
| 历史小图 | 收入与归母利润等，年度与中期分开；各图系列单位、口径和期间可比 |
| 盈利摘要 | 营收、同比、归母利润、同比、EPS等；只用已核验披露或确定性计算，缺项不补零 |
| 预测/估值 | 历史A、预测E与明确假设分开；EPS用元/股、ROE用百分比、P/E和P/B用倍；没有已核验模型就写未建模，不手填比率 |

不得将利润率当市盈率、将营业总收入当营业收入、将母公司或归母口径混为合并净利润。当前引擎支持披露 EPS、稀释 EPS、每股净资产、ROE 原文核验；不提供自动滚动盈利预测或任意 PE/PB 模型。可选 DCF 仍必须提供全部价值桥和明示假设，固定年期结果不能冒充研究日目标价。

## 内页结构与数据板块

目录与图表索引后，十个研究范围按问题展开。标题应写论点，正文交代“发生什么—为什么—对后续判断有什么影响—如何验证”，图表紧接论点。相近专题可双栏；图号、表号连续，单位/期间/范围/来源就在图表下，不能依赖颜色单独传达含义。半栏图必须使用适配的小视图和可读标签，不能把宽图整体缩到小字。

- 业务与行业：业务模式、分部/产品、量价/渠道/客户、产能/供需、竞争及份额；资料不全时标明外部验证缺口。
- 业绩与盈利：年度和当期可比数据、增长来源、成本/毛利/费用/税费、利润质量与一次性因素。
- 资产负债与现金：库存/应收/应付/预收、有息债务/现金、经营现金/资本开支与回报；区分合并金融业务资金。
- 预测与估值：假设驱动表、预测口径、情景与敏感性、价值桥、基准/保守/乐观条件和资料缺口。
- 风险与跟踪：具体风险、反证、需要补证的数据和后续事件。
- 财务摘要：利润表、资产负债表、现金流量表分组，合并/母公司分开、全年/中期/资产负债时点分开；原始披露与派生指标区分。
- 附录：事实/计算、原文观察、来源台账、假设和局限。三表摘要不等于已完成三表预测联动模型。

正文打印约十磅，数据表约八至九磅，三线表、清楚对齐和单位，避免整块深色表头压过数据。页眉给正式报告名，页脚给声明提示与真实页码。目录及索引通过真实内部链接目的页得到页码；不得估算页码或保留伪页码。最终 PDF 有可跳转书签，HTML 保留锚点导航。

## 实际交付

默认生成同一正式名的 HTML/PDF。示例：`贵州茅台（600519.SH）2026中报公司研究报告_2026-10-23.html` 及同名 PDF；程序会做跨平台安全清洗和长度控制。使用本次工具 `artifacts` 绝对路径，不猜固定文件名或把辅助 JSON 裸文件名链接到工作区根目录。

检查真实封面是否为完整摘要页，目录/索引页码是否匹配目的页，标题与下文是否一起分页，图表/三表是否越界或错列，原文/来源是否可追溯。PDF 失败时保留 HTML 与失败记录，修复并用新目录重跑；只有实际双格式及完整摘要校验通过才交付成功。
