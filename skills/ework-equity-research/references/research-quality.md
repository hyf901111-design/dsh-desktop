# 完整研究稿的内容与质量合同

默认 `report.profile: "full"`，交付可追溯、可复算的完整研究，以及同源正式 HTML/PDF。`full` 表示本次研究范围；只有研究、数据、模型和出版交付均满足合同，才可称完整交付。章节数量、页数、图数、引用存在或校验通过均不等于研究完整。

## 必备研究组成

| 组成 | 必须回答的问题与交付内容 |
|---|---|
| 摘要封面 | 核心争议、主要判断、关键证据、改变判断的条件；市场/财务基本数据、历史财务摘要和预测/估值状态齐全 |
| 公司与商业模式 | 产品、渠道、客户及分部如何产生收入、利润与现金；量、价格、组合、周转等驱动如何传导 |
| 行业与竞争 | 终端需求、竞争、定价、渠道库存与份额；区分公司表述、独立行业证据及研究推论 |
| 市场表现 | 估值日向前完整十二个月的实际共同交易日期序列、公司与适合的基准，明确价格/总回报、复权、分红和来源限制 |
| 业绩与驱动 | 多年同口径实绩及最新已披露连续四季度复盘、可比同比；年度、累计中期、派生单季分别比较 |
| 盈利质量 | 毛利、费用、税费、扣非/一次性因素及经营/财务影响，解释变化机制 |
| 资产与现金 | 库存、应收/应付/预收、债务、现金、资本开支、股东回报；穿透金融子公司资金边界 |
| 预测 | 适用经营主体的六年、保守/基准/乐观驱动预测；量价、利润率、税、折旧、资本开支与营运资本连接到 FCFF |
| 估值 | 方法适用性、估值时点、折现率来源与假设、余期/现金滚动、终值再投资、归属与股权桥、独立股本时点、敏感性与反向估值 |
| 风险与跟踪 | 风险机制、对预测的影响、反证、观察指标/事件与下一次检查条件 |
| 财务与附录 | 利润表/资产负债表/现金流摘要分组；事实、计算、来源、假设、定位与限制台账 |

稳定章节 kind 仍为 `business/industry/performance/profitability/balance/cashflow/forecast/valuation/risks/monitoring`；市场、单季复盘和模型可在相关章节作为明确专题，不靠新增空标题取得覆盖。每一组成有实质正文、相关证据和研究含义；多章复用一项收入事实不能证明全部范围已支持。

## 论点、事实与假设

摘要先给投资争议与条件性判断，不从指标清单机械开始。每条核心论点填写 `statement/evidenceRefs/inference/assumption/falsifier/monitoring`：证据支持什么、推到什么、仍依赖什么、什么结果推翻判断、下次怎样观察。相关变化本身不能证明因果。

原始披露、程序推导、研究假设和模型结果分开。未来假设须有稳定 ID、数值/单位/适用期间、依据、理由、来源引用或无外部来源说明。管理层定性表述只支持方向，不自动成为数值指引；研究假设不能冒充公司指引或一致预期。三表摘要不等于完整三表预测联动。

## 不足时的行为

遇到缺数据先继续检索、换可用权威来源、核对原件和工具权限，再明确缺口。对 `partial/missing` 填写 `gap:{missing,impact,nextStep}`，把影响投射到封面、相关章节、模型和交付状态；缺项不补零，不以空表/空标题/一句“待补充”算完成。

缺失驱动 DCF、一年行情、已披露四季度、关键价值桥或来源定位时，不能把 `full` 范围稿称为完整研究交付。可以保留有用的中间研究稿，但显著标为资料不完整，并列明继续补证动作。用户明确只要短评时用 `brief` 并标为非完整研究，不能为了绕过完整合同自行降为简报。

若研究对象是银行、保险等金融主体，先记录 FCFF/WACC 是否适用及理由，选择有依据的金融估值方法；若内置引擎尚不能执行该方法，标明方法与实现缺口。混业公司用有边界的分部估值和股权桥。不能把白酒公司的工业 FCFF、金融持股比例或现金处理照搬到所有公司。

## 定向复核

- 内容：论点与事实吻合，经营驱动连接预测，预测连接现金与价值，风险能反证判断。
- 数据：[市场与季度](market-quality.md)；模型：[驱动预测与估值](valuation-quality.md)。无当时预测档案不画预测命中率或投资策略回测。
- 出版：[封面与内页](publication-format.md)、[图表](chart-quality.md)；打开真实 HTML/PDF 逐页看中文、分页、表格、轴、来源、目录目的页。
- 状态：分别报告事实/计算、完整性、格式交付、来源/经济判断的复核范围。`screen-grade` 仅表示可复算的情景研究；不代表证券研究员签发、自动评级、交易目标价或外部来源真实性认证。
