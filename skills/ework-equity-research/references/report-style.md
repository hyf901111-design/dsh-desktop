# 易方达配色研报

这是配色和阅读规则，不是公司专业研究签发或 PPT 模板要求。报告不擅自添加公司 Logo 或正式签发标识。

| 角色 | 色值 |
|---|---|
| 主标题、结论与主数据 | `#005096` |
| 次级蓝 | `#0078B4` |
| 对比系列、连接和强调 | `#1EB9E1` |
| 标题青 | `#00BEE6` |
| 弱分组 | `#B3EBFF` |
| 正文、次级灰 | `#3C3C3C`、`#969696` |
| 分隔线 | `#C1C6C8` |
| 单一风险/重点信号 | `#FFC819` |

白底留白，深蓝承担层级、青色承担对比，灰色承载注释。图表颜色不承担唯一语义，同时提供数据标签、表格或文字。金额、百分比、亿元、百万元、股数和每股数据不得共用模糊单位。

首屏依次让读者知道：研究对象与截止日、研究判断、核心证据与尚未解决的条件。正文标题写出论点，数据图表就近注明 source/期间/scope；报告末尾列来源和假设/局限。未核验市场数据时只说明未评级/未建模状态，不给目标价或评级建议。

正式封面与内页以 [出版规范](publication-format.md) 为准：摘要封面双栏、财务摘要、编号目录/图表索引、三线表与财务三表摘要。主副标题分层，文件、文档元数据和页眉使用正式报告名；观点大标题独立。参考报告的红色强调统一替换为当前深蓝/蓝青，不沿用原机构标识和数字。

正文采用中文书面报告字体，正式打印约 10pt、封面摘要约 9–10pt、表格约 8–9pt，屏幕保持可读。A4 自动分页、重复表头、避免标题孤立和表格越界；不能缩放整页压字或隐藏溢出。自包含 HTML/SVG，不加载 CDN。默认从最终 HTML 导出 PDF 并检查实际页码和版式；PDF 与网页复用同次研究内容及证据。正文先呈现可读的研究推理与专题表图，技术事实ID、公式和长摘录放入后部附录。图表按研究问题配置并比较可比期间，不按输入顺序混排全年与半年。
