# 易方达 PPT 制作助手 · 1.1.4

先根据用户交付的材料和改动范围选择工作方式。技能资源的相对路径均从本技能目录解析，脚本以客户端任务 Python 的 `python3 -B` 执行。技能目录只读。

## 优化已有 PPTX 的版式

适用于“优化一下版式”“排得好看些”“基于新版再排一下”等请求。以这次指定的 PPTX 为唯一输入，另存可编辑副本。延用用户认可的风格，以新版的页序、文字、数字、注释和嵌入附件为准。原稿的单目录、封面、母版与页脚直接继承。用户明确要求增删、改写或换模板时才改变相应内容。仅排版时直接开始工作。

1. 一次运行 `python3 -B "$SKILL_DIR/scripts/layout_edit.py" inspect "$SOURCE"`，得到源文件指纹、版心和按放映顺序排列的对象 ID、尺寸、段落序号、表格行列与合并信息。使用当前环境可用的演示软件渲染原稿到私有临时目录。结合实际图像判断哪些页面需要调整。
2. 按信息关系为受影响页面写一份小型 JSON 计划。用 `layout_edit.py apply` 一次应用到新文件。格式、表格和段落重排示例见 [已有稿排版](references/layout-edit.md)。以实际内容决定需要调整的对象。对工具不支持的图表、组合或特殊版式，保留原生对象，按需对有关页单独编辑。
3. 表格为说明列留足空间，同列对齐，利用行底色区分类别；五项以上的指标适合按行比较。年度要求和业务特征分别成表。项目清单可把完整标题和原文分排到两栏；时间线把已有日期与事件对齐。普通正文左对齐。正文区小标题底边与正文首行留一行正文高度；为底部附件、页脚留出保护区。品牌中文字体使用华文黑体_易方达，西文和数字用 Arial。
4. 对最终文件运行 `scripts/check_efund_package.py`，与源稿核对文字、页序、表格和附件。用最终渲染逐页实看标题、孤行、页脚、数字、图标和文字碰撞。macOS 上获准控制 PowerPoint 时，使用随包的 [原生复核脚本](scripts/review_layout.applescript) 逐页访问并导出 PDF，再检查渲染；环境不具备时说明实际验证范围。发现问题只改有问题的布局，在同一份计划上迭代。只把用户需要的文件放进交付目录。

已有稿的局部版式优化按上述流程完成。全套模板映射、重复章节目录、新稿隐私清理及原创结构报告用于下面的完整制作流程。仅在明确要求外发或脱敏时对现有材料执行清理；业务数据、备注和附件有实际用途。

## 新建、套模板、续写、正式发布或全面审计

遵循 [完整制作规范](AUTHORING.md) 的全部流程，包括封面、品牌资产、字体、结构、原生兼容性与逐页视觉检查。原稿供提取内容、用户要求重构或指定更换模板时，也按该规范选择品牌来源并制定映射。文字改写或创建新页时读取其对应的设计、表格、图表与文案契约。
