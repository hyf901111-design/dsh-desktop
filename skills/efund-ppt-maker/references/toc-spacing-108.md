# 1.0.8：目录紧凑排列

目录不是需要铺满的正文图表。沿用唯一源模板目录的首行位置、原始行高、行距、字号及数字/标题列对齐。四个章节只占前四行，下方自然留白；禁止用“可用高度 ÷ 章节数”、垂直均匀分布、space-between 或拉高表格的方法补满页面。不能通过缩小字号来弥补错误行距。

先读取源目录的真实几何。原生表格的 `a:tr/@h` 是行高，`p:graphicFrame/p:xfrm/a:off/@y` 是起点；删除多余行时把整体高度改成保留行高之和，不能继续沿用七行表格的总高度。原生表格或独立文本框均可保留源排布；改成文本框时，用原单元格的行中心定位，保留内边距与垂直对齐。数字、标题和分隔线同步移动，不能只压缩标题列。只保留实际目录行对应的分隔线。

目录项优先保持单行，长标题先精简措辞；仍无法容纳时按实际文本高度局部扩行或拆分导航，记录源稿依据并检查阅读顺序，不能为了填满页面扩大所有行。章节数超过源目录容量时先调整章节层级或拆分导航页；不能把正文页挤成小字目录。

同一份文件的章节导航复用同一组目录几何，只有即将进入的章节标题高亮变化。保持 1.0.7 的“目录→该章正文→下一张目录”顺序。

## 间距检查

在 `outputSlides` 每张目录页增加 `tocLayout: {sourceSlide, sourceTableId}`，指向唯一源稿中选用的目录表格。`tocRows` 的每行仍包含章节标题 `shapeId`，并新增 `numberShapeId` 指向编号文本框；标题框及编号框中心分别对齐源表格对应行中心。检查器从源文件读取行高，不接受手填行距作为通过依据。沿用源表格时，可用 `{tableId,rowIndex,columnIndex}` 代替 shapeId，编号用 `numberCell: {tableId,rowIndex,columnIndex}`；索引均从 0 开始。

运行 `check_efund_delivery.py` 检查成品实际行中心。源对象或行缺失要修复映射，不能跳过检查。导出后比较全部目录缩略图，重点检查四行目录下方留白、首行位置、编号和标题对齐、重复目录几何一致。结构检查不等于视觉检查，报告应如实区分。
