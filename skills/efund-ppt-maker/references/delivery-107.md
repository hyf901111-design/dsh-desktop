# 1.0.7：标题、表格、章节导航与原创正文

这些要求用于新生成和后续修改的 PPT，不要求自动重写用户已有文件。

## 标题不能靠近似重画

先在唯一源稿中定位普通内容页的标题对象和它实际继承的布局占位符。复制整个标题框，只改文本 run；保留 x/y/宽/高、文本内边距、垂直锚点、段落设置和源字号。禁止使用新建文本框的默认 `(0,0)`，禁止把标题条的坐标当作标题文字坐标，也不要再次复制已存在的母版标题。不同编辑引擎的 inch、pt、px、EMU 必须在入口统一，不能混用。

在归一化 960×540 图中，文字左边缘应与源标题一致，垂直位置应处于原标题条内；不以任意通用坐标代替模板坐标。长标题精简或拆页，不能移动标题框救场。最终文件必须在 PowerPoint/兼容渲染器里检查，特别检查首张正文、最长标题和所有不同页型。

每张正文和目录页的 `outputSlides` 映射增加 `titleAnchor`，包含 `sourceSlide`、`sourceShapeId`、`sourceScope`（slide 或 layout）以及 `outputShapeId`。检查器对比成品与源框几何（0.5px 容差）和内边距/垂直锚点；继承对象须正确导出实际占位符，无法解析时不能把结果当通过。

## 表格明确关闭边线

对比和分组表格：无外框、无横线、无竖线、无合并单元格残留线。靠青色表头、白/浅灰行底色、间距和对齐区分，不使用黑色格网。不是把边线宽度设为 0 就算关闭：主题可能恢复边线。原生表格逐单元格设置左、右、上、下和两条对角线 `a:noFill`，合并单元格也检查。形状拼成的表格用 `table-*` / `grouped-table-*` / `comparison-table-*` 命名，并显式设置线条 noFill。表头和结论行也不得有外框。

任务清单若需要细水平分隔线，使用独立 `task-list-horizontal-rule-*` 线条，不把它做成单元格描边。其他原有表格文字与字号规则继续适用。

## 每章开始前重现目录

分章材料顺序为：封面 → 完整目录（高亮第一章）→ 第一章的一页或多页正文 → 完整目录（高亮第二章）→ 第二章正文 → …… → 最后一章正文 → 结束页。不能只在开头放一张目录，也不能开头就高亮第二章。每张目录保留全部章节的名称、编号、位置与顺序，仅当前即将讲解的章节标题为源模板蓝色，其余标题为浅灰。目录数字与品牌家具按源模板保留。目录不应连续出现，不在章节内部重复，不在最后一章之后增加没有后续正文的目录。

顶层 `chapters` 为有序的 `{id,title}` 数组。所有 `outputSlides` 按最终逻辑页码排列，声明 `pageKind`：正文为 content，并填 `chapterId`；目录为 toc，并填 `activeChapterId` 及完整 `tocRows:[{chapterId,shapeId}]`，其中 shapeId 对应仅含章节标题的文本框。源模板默认蓝色为 00529B、灰色为 D9D9D9，实际不同则填 `tocActiveColor` / `tocInactiveColor` 并在模板审计中记录依据。标题 run 显式写入最终 RGB，防止主题颜色被错误继承。单章短材料可不插目录，但仍要声明章节；多章不可省略导航。

## 正文布局由论点和证据决定

模板只提供品牌壳、文字规范和视觉语法。先写该页的结论、证据、关系与阅读路径，再画几何草图，再查看案例作风格校准。不能先挑一张案例再把主题词替换进去。内容结构相近时允许一致布局，但要能解释为何它支持理解；换配色、图标或卡片数量不算新结构。

人物生平可以用有史料支撑的时间线与事件特写；思想关系可以用命题—例子—边界、概念关系图或原文与解释；作品比较可以用共同维度的无框矩阵。这些只是可能方案，不是必须轮流使用的模板菜单。可根据具体材料采用其他结构。不要把年份、著作数量等无比较价值的数字强行做成整页大数字卡片。

版式审阅要看整份缩略图：每页有独立的主焦点与合适的信息密度，连续页面的节奏服务于叙事。`layoutDecision` 记录“该页内容为什么需要这个几何关系”和“对案例做了哪些结构调整”；复用正文必须通过既有 reuseEligibility 条件。若多个主题都能仅靠换字套进同一页，这页通常仍缺少内容专属设计。

## 导出验收

运行 check_efund_delivery.py 与原有几何、字体、文案、隐私检查。逐页渲染要检查实际文字基线、无边线表格和每个章节转换。生成图的预览能力与模型视觉能力分开：不支持图片输入时使用结构检查和客户端预览，并如实说明尚未完成模型视觉审阅，不能声称自己看过图片。不得把截图无法读取当作修改字体或绕过 QA 的理由。
