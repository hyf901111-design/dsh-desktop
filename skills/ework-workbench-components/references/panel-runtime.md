# 工作台单面板生成摘要

同版 SKILL.md 及 Figma、适配验收、Runtime 规范摘要，仅供单卡执行。宿主 `21m-20260923-v1` 执行完整设计。输出协议以本次宿主为准：开放 submit_component_data 时提交 requests/mapping，否则交一个完整 v1 JSON；不附分析/计划/代码围栏/其他组件。

先理解本卡问题和必要交互，再取得并核对实际数据，最后按真实字段和维度选择呈现。规划类型是建议，模板指导样式与交互，不要求数据补齐模板字段；可换允许的呈现，但保留用户明确图形、来源、范围和功能。成功响应由宿主保留，使用路径映射完整记录，不抄写长序列；校验错误在当前任务修正，不为格式问题重新取数。单值先按证券/报告期/报表类型明确筛选，最新记录显式排序并取一条；仅整行完全重复可等价处理，不同记录不任取。缺失允许时用 $optional:true。交易日 YYYYMMDD 由宿主等价转为 YYYY-MM-DD，非法日期和OHLC关系仍校验。

本摘要沿用loader强制头的模式/样式/状态规则；不重复宿主壳，保留业务分节标题、筛选与用户布局。原稿实例不决定当前chrome。

失败先分类：宿主无损归一化 → 一次复用已有响应的定向修复 → 换能承接原需求的宿主方式，不机械重复生成或取数。表格单元格按单值编译，单元素包装可等价展开，多个不同记录不任取。普通表格修复仍失败可展示完整来源明细，明确原对比/交互/刷新尚未完成；明确图形、筛选、排序、来源和刷新要求不得被静态视图替换。暂时性网络故障在宿主有限预算内仅重试失败请求，再按原授权换可用来源并核对口径；指定来源不擅换。来源/单位/日期冲突及多记录歧义不以降级消除；权限拒绝或取消立即停止恢复链，不换工具绕过。无真实资料不以说明卡冒充完成。

- 主要字段、数值、图例、单位、时间、来源和必要交互全保留。复用宿主证据，优先用其列出的当前会话可用专业工具覆盖需求，遵守工具授权/调用确认；仅补缺口，资料够即交付。原生单证券行情的 selectedSymbol 必须对应 symbols 内唯一证券，不因此启动逐根生成。真实数值/日期/链接须可核查；仅需求明确允许时使用并标注演示数据，不伪造实时行情或持续监控。
- 根据实际数据选用适合的宿主视图，不重复样式：金融数值用 `market.metrics`，可排序多标的明细用 `market.table`，真实详情 URL 可放逐行 `rowLinks`；金融趋势用 `market.trend` 的 `labels`/`series`。医药组合：侧栏对比 `market.scatter`、研发进度 `market.pipeline`、底部催化 `market.events`。实时单证券K线优先直接挂载原生行情组件；明确历史快照、模拟或原生不支持的资产用 `chart.candlestick` 或 `market.candlestick`：单标的 `candles`，多标的 `datasets:[{symbol,name,candles}]`；无可核验日线时保留标的的 `candles:[]` 及 `missing` 原因。蜡烛为 `{date,open,high,low,close,volume}`；缺成交量填 `null` 并说明，不填零或编造。均线/标的切换/可用区间由宿主负责。K 线不用折线或自写 HTML；主要数据不塞进 `note`，缺失就地说明，保留已有有效内容。
- 通用自动布局选完整可读的最小规格：S 320×220、M 656×220、L 656×456；金融模板用 Figma 源节点尺寸。手动拉框保留宽高并重排，不缩整卡字号、不裁切或折叠隐藏主要字段、不重复宿主标题。
- 通用正文 12/18px；金融指标按源节点 `1217:225751` 用 DINPro 21/26px，金融外壳/表格各遵源节点，勿用通用 23/26px 或 12px 内边距覆盖金融模板。控件黑白灰；行情/风险色仅表达实际数据语义。支持深浅主题，来源、日期、单位就近标注。

结构化输入用type=form、代码阅读用type=code，均有宿主固定模板。form提供fields:[{id,label,kind,required,value}]，select提供options:[{value,label}]；仅保存本画布输入记录。code提供language和content字符串，不执行代码；JSON格式化、复制和下载由宿主完成。

世界时钟用type=clock，提供version:1/title/asOf和locations:[{id,label,timeZone}]，timeZone必须为有效IANA时区（如Asia/Shanghai、America/New_York）。mode默认live使用设备当前时间；固定时间用mode:snapshot及带Z或偏移的ISO currentTime。可选selectedId、hourCycle:h23或h12，宿主负责夏令时、跨日、城市切换和小时制。时钟更新时间不等于行情刷新时间。


YouTube视频用panel.type=youtube，首次同时提交artifact:{version:1,type:"youtube",title,url,description?,durationSeconds?,thumbnailUrl?,subtitles?}，使用source模式。不提供网址时url:null，宿主显示Figma网址输入空态；只使用用户原视频网址，不猜测视频、不生成HTML或逐卡任务。已取得的时长秒数、封面原网址、完整字幕和说明保留，未知资料不编造。支持watch、youtu.be、shorts、embed、live视频地址；宿主采用YouTube官方播放器，不自动播放，重新载入仅表示加载请求。

音频使用 panel.type=audio，首次提交 artifact:{version:1,type:"audio",title,url,description?,source?,date?,durationSeconds?,waveform?,transcript?,chapters?}。仅使用本人明确提供的无凭据HTTP/HTTPS音频原网址；未提供时url:null显示添加音频空态。时长单位秒，waveform仅为实际取得的0至1振幅数组，chapters:[{title,startSeconds}]，转写完整保留。未知时长、波形和转写不编造；不合成音频或HTML、不启动逐卡模型、不自动播放。采用source模式。 宿主保留完整转写、章节和来源，播放器控制随窄卡换行；会话切换暂停音频并记住当前进度、速度和音量，返回后由用户继续播放。重新加载只表示已请求加载音源，实际成功或失败由媒体事件显示。Figma 1918:353063，默认656×264，统一最小280×180；来源网址保存不代表应用重启后恢复临时播放进度。

文件使用 panel.type=files，图集使用 panel.type=gallery。首次同时提供完整 artifact:{version:1,type,title,items:[{id,name,url或relativePath,description?,source?,date?,sizeBytes?,mimeType?,alt?,permissions?:{preview?,download?,remove?}}]}，采用 source 模式，宿主直接 prepared，不生成HTML或逐卡模型。每项只允许一个原来源：本人明确提供的无凭据HTTP/HTTPS网址或当前工作目录内相对路径；未提供时url:null或items:[]，不编造样例。authorizationId仅由用户在客户端导入产生，模型不创建或猜测。保留完整长文件名、原0/负数/未知说明、原来源、图片alt和元信息。sizeBytes为真实字节数，未知省略或null，不补零。预览、下载、移除权限独立；移除只删本卡引用，原文件保留，可画布撤销恢复。Figma文件1918:347373默认656×410、图库1918:347930默认656×364，统一最小280×180；缩略图只用于浏览，原图预览和下载保持原始字节。导入进度显示实际完成文件数，失败可重试；已完成附件保存授权后可恢复，未完成导入不声称跨重启恢复。HTTP原文件下载不复用网页登录Cookie，不自动跟随重定向，单文件32MB；仅用户确认实际保存后显示成功，取消或失败如实显示。重新载入只请求原文件预览，不改写附件清单或生成新数据。


### 交付恢复与来源进展

- 模板负责样式和交互，来源决定内容。客户端原生渲染结果再次进入校验时，只在与当前模板重新渲染的结果完全相同时恢复为原始结构化数据；不能仅凭模板标记跳过自定义 HTML 校验。禁止让模型为修复客户端模板错误重写已取得的数据。
- 同一目录连续两次关键词搜索返回空 interfaces 时停止重复改词，不能据此认定整个目录无可用接口；仍允许按尚未查询过的明确 api_name 读取定义，同一接口名已返回空定义则不重复查询。取得有效定义后应先执行业务取数，不在只有目录时直接生成；客户端在原有调用次数与总时限内给首次业务读取有限时间，空目录和失败调用不延长预算。权限失败不扩大访问，不猜接口或失效工具名。保留已取得的完整记录，只补缺少范围。未取得材料须保留缺失状态，不能用示例数值、少量记录或空图冒充完整交付。
- 原生渲染结果须在来源、覆盖范围和最终呈现校验之前恢复经宿主逐字重渲染核对的结构化模型，保留 sources、明细、null 与原始精度；提交工具接受呈现不等于来源与完整性验收通过。
- 图标工具栏的按钮采用固定方形点击区与 inline-flex 双轴居中，图标 display:block、margin:0；hover、选中背景与图标同心。通用控件的内边距、行高不得覆盖此几何，窄宽换行仍保持居中。


## 有界恢复与交付测量

获取材料后，优先一次调用 `component_presentation_schema({type,variant})`，同时取得当前 sourceRef、实际嵌套数组路径、完整条数和呈现协议；直接映射已保留的全量响应，不再反复查询空参数协议目录，不手抄长序列。未知字段的业务含义仍须根据来源确认，不凭字段名猜测。

确切接口定义为空或同一目录连续两次关键词检索为空时，停止重复同一空查询，在现有工具授权和既有调用次数上限内换来源或读取原网页。该阶段最多延续到135秒；取得可用数据立即进入交付，不能借切换来源新增权限、无限延长任务或使用虚构记录。指定来源不可用时说明缺失，不擅换口径。数据获取、内容处理、呈现与验收分别判断；呈现失败不丢掉真实数据重新开始，复用当前材料修复或换成满足同一需求的可交付视图。无法满足原需求时明确未完成，不把残缺、空卡或无效按钮当作成功。

生成占位状态使用稳定初始高度，不测量占位网格或动画为内容，连续整理必须幂等。组件完成后，按真实内容与默认交互状态自动重算阅读高度，移除占位遗留空白并让后续组件避让；分页按当前页行数测量。保留用户明确调整的尺寸，窗口自适应与自动测量不重写共享原始内容或数据。
