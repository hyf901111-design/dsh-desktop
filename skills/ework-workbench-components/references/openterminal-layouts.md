## 复用优先级与完整目录

1. **保留市场指数、自选股、个股行情**：`financial-widget.indices/watchlist/quote` 继续当前组件库的布局、数据联动、专业图表与交互；不改写成 OpenTerminal 对应组件。市场指数的多指数小图矩阵、自选股的市场/代码/名称与涨跌列、个股行情的价格读数/周期/MA/VOL/MACD 均沿用。
2. **其余新生成组件优先复用下面 13 类布局**；按业务内容匹配，不能只改主题色。表格、行情快照、量价图、新闻已有独立宿主 profile；其他目录复用同类宿主的数据与交互能力，按以下分区表达。目录是生成选型规范，不代表下列每项都已新增独立运行时 widget。
3. **排除图 2 和图 3**：不采用 ChartWidget 和 WatchlistWidget；不复制其专业证券图表工具条、简化自选列表与增删入口。量价分析继续使用 EWork 的动态绘图引擎；不将量价模板说成导入了被排除的专业图表。
4. 用户明确指定其他设计来源时遵从；未覆盖的任务才使用原有 Figma 组件规范。原有卡片不因新增规范被重写。

| ScreenerWidget / 证券筛选 | 一行筛选条件、数量状态、可排序多列表；数字右齐，行业和名称左齐 | `market.table` + OpenTerminal profile；只展示可实际执行的筛选，不画无作用控件 |

| MacroWidget / 宏观概览 | 地区/时点工具区，收益率或重要指标的比较区，指数/商品的三列列表；单位逐项保留 | `market.table`、`market.trend`；不同量纲拆图区，不强行堆成 KPI 卡 |

| PortfolioWidget / 组合持仓 | 组合/持仓与交易页签的紧凑工具区，汇总读数行，持仓数量/成本/价格/市值/盈亏明细 | `market.table` + OpenTerminal profile；新增/删除仅使用已有本看板编辑能力，不伪造真实交易动作 |
| AiWidget / 上下文分析 | 当前标的/来源上下文条，连续研究文本与清晰的分段信息层级，下一步入口紧邻内容 | `note` / `summary`；后续提问沿用宿主原有入口，不另造无法发送的聊天框 |
| CalendarWidget / 经济及财报日历 | 经济/财报分组与日期/时区行，事件/币种/预期/前值/公布值表；财报历史使用季度对比行 | `market.table` + OpenTerminal profile；按天安排可用 `calendar`，日期不确定保留原文，不冒充实际公布 |
| InsiderWidget / 内部人交易 | 同一公司上下文，日期/交易人/职务/类型/股数/价格/金额/交易后持股密集表，买卖颜色仅表示来源方向 | `market.insider-trading` 保留专用数据契约；普通静态明细用 OpenTerminal `market.table` |

以上布局的共同特征是**连续的信息层级、紧凑标签值行、对齐的数据表、适当的图区与来源区**。既有宿主暂未实现的镜像表头、分区组合、专属筛选等不靠提示词冒充已实现；先使用能完整保留数据的可用结构，并记录具体待适配项。不要为复用名称而丢失功能、来源、记录或单位。

## 已实现的四类宿主布局


| 数据任务 | 数据模板 | 新布局结构 | 默认外框 |
| --- | --- | --- | --- |
| 单标的报价快照 | market.ticker-information | 证券身份行 → 主报价与涨跌并排 → 双列 label/value 细分隔行 → 历史读数和完整记录 | 448×400 |
| 价格与成交量 | market.price-volume | 最近报价/变化读数带 → 区间工具行 → 上价格、下成交量双图区 → 图例和完整记录 | 832×340 |
| 行情观察池 | market.table | 记录概览 → 搜索/数量工具行 → 固定表头和首列的数据网格 → 选中读数 | 832×400 |
| 新闻/研究信息流 | news | 搜索和分类 → 时间/分类/来源窄栏 + 标题/完整摘要宽栏 → 摘要就地收展 | 448×400 |

所有对象显式附 `layoutProfile:"openterminal"`，数据仍使用该类型原契约。仅这四类已实现，不能将其他类型标成相同布局冒充支持。标准快速预设为 `openterminal-research`，面板顺序为窄行情、宽图表、窄新闻、宽表格；同列宽度一致，避免短卡旁出现无用空洞。

原组件顶栏保留标题、提问、菜单、关闭等原元素与行为；底栏保留来源、时效、刷新状态、数据源和连接端口。不在正文重做一套顶栏、底栏或关闭按钮。外框使用当前看板的 OpenTerminal 试用样式和右下角缩放。OpenTerminal 下的菜单、数据设置弹窗及生成卡全部配套现有深色主题，不能因客户端处于浅色而变白；生成过程保留原深色圆角进度卡和深色网格，完成后再用终端外框。

## 阅读与交互

- 行情主价格 30px，涨跌相邻；辅助指标按标签和值左右对齐，不做一组等大 KPI 卡。零值、负值和缺失原样保留；每项单位、周期和时点由数据提供。
- 图表沿用 EWork 专业引擎（不导入被排除的 ChartWidget），按实际容器宽高重绘，文字保持 CSS 像素字号；方向键逐点读数，已有范围控件和完整原记录继续可用。价格和成交量各用独立区域及单位，不将异量纲曲线叠入同轴。
- 表头与表体共用同一列宽、左右内边距和对齐基线；数值列表头与值的右缘视觉对齐。表头的单位优先写为“最新价 / 元”，避免末尾全角括号的留白造成视觉偏移。搜索框与“8 / 8 项”等计数至少留 12px 间距，计数不紧贴输入框，窄框换行后仍保留间隔。
- 表格数字右对齐，文本左对齐，使用等宽数字；首列在横向浏览时保持可见。默认所有单元格单行，宽列横向滚动；保留列宽拖动与手动窄列换行。排序、搜索和选中详情不能丢失原行或涨跌语义。
- 新闻标题允许完整换行，摘要默认完整可读并能折叠。时间、分类和发布者分层，已核验原文可点击；没有链接不造链接，没有发布时间不借用获取时间。不得照搬上游一行省略号隐藏标题与摘要。
- 280–360px 时行情键值改为单列、新闻元信息改为同行换行；工具栏换行，表格保留横向浏览。高度不足时内部滚动，不缩小整卡、不裁掉数据。

## 试用与验收

`layoutProfile` 决定结构，底栏看板样式决定配色，两者分别持久化。切回旧颜色不会删除这张新卡的布局 profile；原有组件未指定 profile，继续原有布局。刷新、搜索、调整尺寸后必须保持结构和完整数据。

效果看板所有证券、价格与新闻均为虚构模拟，标题与时点显著注明。客户端验收至少覆盖：四种新布局、表格搜索/排序、图表范围/键盘读数、新闻分类/折叠、窄宽尺寸和原顶底栏入口。静态预览不能替代客户端实际生成证据。显式 OpenTerminal 表格保留完整宿主 HTML 布局，不能经仅提取单元格的原生表格优化丢失概览、口径和说明区。

本地验收预设：`openterminal-research` 综合研究四卡、`openterminal-portfolio` 组合/宏观/披露/财报四张密集表、`openterminal-briefing` 能源简报四卡。均使用 `dataMode:"simulated"`、`panels:[]`，一次调用即由宿主生成，不读取真实用户持仓、不获取外部数据。
