# OpenTerminal 组件内布局试用 v1

来源：ErTasselli/OpenTerminal 提交 `aed097c680cd8ec1c391ae06966babe7d6d91fc6` 的 QuoteWidget、ChartWidget、NewsWidget 和 data-table。MIT 许可随客户端保留于 `build/openterminal/LICENSE`。这是 EWork 的宿主适配模板，未引入 OpenTerminal 的业务服务或外部视频依赖。

## 结构与选型

| 数据任务 | 数据模板 | 新布局结构 | 默认外框 |
| --- | --- | --- | --- |
| 单标的报价快照 | market.ticker-information | 证券身份行 → 主报价与涨跌并排 → 双列 label/value 细分隔行 → 历史读数和完整记录 | 448×340 |
| 价格与成交量 | market.price-volume | 最近报价/变化读数带 → 区间工具行 → 上价格、下成交量双图区 → 图例和完整记录 | 832×340 |
| 行情观察池 | market.table | 记录概览 → 搜索/数量工具行 → 固定表头和首列的数据网格 → 选中读数 | 832×400 |
| 新闻/研究信息流 | news | 搜索和分类 → 时间/分类/来源窄栏 + 标题/完整摘要宽栏 → 摘要就地收展 | 448×400 |

所有对象显式附 `layoutProfile:"openterminal"`，数据仍使用该类型原契约。仅这四类已实现，不能将其他类型标成相同布局冒充支持。标准快速预设为 `openterminal-research`，面板顺序为窄行情、宽图表、窄新闻、宽表格；同列宽度一致，避免短卡旁出现无用空洞。

原组件顶栏保留标题、提问、菜单、关闭等原元素与行为；底栏保留来源、时效、刷新状态、数据源和连接端口。不在正文重做一套顶栏、底栏或关闭按钮。外框使用当前看板的 OpenTerminal 试用样式和右下角缩放。

## 阅读与交互

- 行情主价格 30px，涨跌相邻；辅助指标按标签和值左右对齐，不做一组等大 KPI 卡。零值、负值和缺失原样保留；每项单位、周期和时点由数据提供。
- 图表使用 EWork 专业引擎，按实际容器宽高重绘，文字保持 CSS 像素字号；方向键逐点读数，已有范围控件和完整原记录继续可用。价格和成交量各用独立区域及单位，不将异量纲曲线叠入同轴。
- 表格数字右对齐，文本左对齐，使用等宽数字；首列在横向浏览时保持可见。默认所有单元格单行，宽列横向滚动；保留列宽拖动与手动窄列换行。排序、搜索和选中详情不能丢失原行或涨跌语义。
- 新闻标题允许完整换行，摘要默认完整可读并能折叠。时间、分类和发布者分层，已核验原文可点击；没有链接不造链接，没有发布时间不借用获取时间。不得照搬上游一行省略号隐藏标题与摘要。
- 280–360px 时行情键值改为单列、新闻元信息改为同行换行；工具栏换行，表格保留横向浏览。高度不足时内部滚动，不缩小整卡、不裁掉数据。

## 试用与验收

`layoutProfile` 决定结构，底栏看板样式决定配色，两者分别持久化。切回旧颜色不会删除这张新卡的布局 profile；原有组件未指定 profile，继续原有布局。刷新、搜索、调整尺寸后必须保持结构和完整数据。

效果看板所有证券、价格与新闻均为虚构模拟，标题与时点显著注明。客户端验收至少覆盖：四种新布局、表格搜索/排序、图表范围/键盘读数、新闻分类/折叠、窄宽尺寸和原顶底栏入口。静态预览不能替代客户端实际生成证据。
